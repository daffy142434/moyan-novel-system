# 海外剧本格式与样稿拆解

## 格式来源

基于已过稿海外狼人题材短剧《Alpha's Vengeance》（狼王嫡女复仇录）拆解，此格式为甲方验收通过的标准格式。

## 一审提交材料结构

一审提交物：**大纲 + 一卡提审**，打包为压缩包，命名规则：`公司简称+日期+本数`（如 `茗舒20260715x3`）。

### 1. 剧本简介

必须包含以下字段：

- **题材**：一句话定义类型（如"奇幻狼人、嫡女蒙冤复仇微短剧"）
- **元素**：核心元素标签，用顿号分隔（如"贵族狼人家族、牢狱伤残、全员恶人原生家庭、暗中取证、神秘强者单向守护..."）
- **篇幅**：集数 + 每集时长（如"预计60集，每集1-3min"）
- **故事亮点**：4-5个卖点，每个用①②③编号，先写亮点名称加粗，再用冒号展开一句话说明
- **一句话简介**：完整故事线压缩为一段话，包含主角名、核心困境、关键转折、最终结局

### 2. 主要人物（人物小传）

每个角色包含：

- **角色名**：英文名（海外市场必须用英文名）
- **身份标签**：一句话定位（如"正统狼王嫡女"、"现任狼王，女主生父"）
- **年龄**（如适用）
- **性格关键词**：3-4个核心性格词（如"坚韧隐忍、恩怨分明、极强独立人格"）
- **核心设定**：角色在故事中的功能、独特能力、与主角的关系
- **【形象描述】**：用方括号标注，写外貌、服装、标志性特征（如"身形清瘦，灰黑狼耳，冰蓝竖瞳，右腿银刑假肢"）

角色按重要性排序：主角 → 主要角色 → 主要反派。已故角色标注"已故"，可省略形象描述。

### 3. 故事梗概

完整的故事从头到尾，一口气读完能理解整个故事。包含：

- 主角初始处境与核心困境
- 回归/进入冲突场的触发事件
- 中段冲突升级与取证/成长过程
- 关键转折（真相揭露、阵营倒戈等）
- 高潮对决
- 最终结局与格局升华

篇幅：500-800字。

### 4. 集纲总结（一卡集纲）

按阶段分组概括，每3-5集为一个阶段：

**格式：**
```
X-Y集 阶段标题（动宾短语，概括本阶段核心事件）
一段话描述核心事件，不超过200字。重点写：谁做了什么、冲突是什么、结果如何、留了什么悬念。
```

**示例：**
```
1-3集 蒙冤归巢，初识暗中守护者
Serafina拖着伤残假肢刑满出狱，兄长Kilian以Mary性命胁迫她返回狼族庄园。回到家中，继妹Ivy当众挑衅...女主被关进潮湿带银锁的地下杂物间，立下复仇誓言。

4-6集 暗中取证，家族内讧加剧
女主安顿后持续记录家人各类加害行为...Garrick多次暗中现身，默默替女主清除暗杀陷阱。
```

## 二审提交材料

一审确认后，补充提交以下四项供甲方确认：

1. **人设确认稿**：在一审人物小传基础上细化，补充角色弧线变化
2. **故事梗概确认稿**：根据一审反馈调整后的完整梗概
3. **大纲确认稿**：完整集纲
4. **分集细纲**：每集详细场景和事件拆解（每集列出场次、出场人物、核心事件、爽点、钩子）

## 分集剧本格式（过稿标准）

### 场景头

```
集数-场次 地点 日/夜 内/外
```

示例：
- `1-1 狼人劳役场大门 日 外`
- `1-2 庄园客厅 日 内`
- `2-3 后院回廊 日 外`

### 出场人物

紧跟场景头下一行：

```
人物：角色A、角色B、角色C
```

### 动作/场景描写

以 `△` 开头，每个动作独立一行：

```
△荒原无边无际，厚重的银钉铁门，墙面积满狼血的痕迹，远处的囚徒哀嚎不绝。
△Serafina身穿一身灰旧劳役的囚服，右腿金属假肢，满身银鞭伤疤，灰黑狼耳无力耷拉。
△狼族狱警身穿银纹看守制服，快步上前，抬脚，踹向Serafina残肢的伤口。
```

**动作描写要求：**
- 写镜头能拍到的具体动作，不写心理活动
- 环境描写简洁有画面感，一行搞定
- 角色首次出场必须写外貌/服装/标志性特征
- 肢体细节外化情绪（"狼耳紧绷""爪尖掐破掌心""浑身狼毛炸开""狼尾疯狂抽打空气"）

### 台词格式

```
角色名（情绪/动作）：台词内容
```

示例：
```
Kilian（鄙夷）：一身伤疤，一条废腿，成为全族的笑柄，若不是父亲逼迫，我才不愿接你。
Serafina（沙哑冷冽）：当年你们伪造罪证，送我入银狱，我们早就没有关系了。
Helena（厉声指责）：刚回来就冲撞Ivy，你恶毒的本性，竟然五年都没改！
```

### 内心独白/旁白

```
角色名（VO）：内心独白内容
```

也可与情绪标注结合：
```
Serafina（淡然笃定，VO）：等她清醒，你们伪造的全部证词，都会作废。
```

**VO 使用原则：** 不滥用，只在主角做出重大决策、揭示关键信息差时使用。

### 自言自语

```
角色名（低声自语，情绪）：台词
```

示例：
```
Garrick（低声自语，情绪兴奋）：我找了你好久。
```

## 每集规格

| 项目 | 海外仿真人原创 | 海外AI剧本 |
|------|----------------|------------|
| 总集数 | 50-60集 | 50-60集 |
| 每集字数 | 600-700字 | 600-800字 |
| 每集时长 | 1-3min | 总时长约100min |
| 每集场景数 | 2-3个 | 2-3个 |
| 结尾要求 | 必须留悬念/钩子 | 必须留悬念/钩子 |
| 爽点密度 | 每集至少1-2个冲突升级或爽点 | 每集至少1-2个冲突升级或爽点 |

## 角色命名规则

- 海外剧一律使用英文名
- 名字要符合目标市场文化（欧美/东南亚/中东）
- 避免中文拼音直接做名字
- 反派名字可以稍有辨识度但不要太夸张

## 写作风格要点（从样稿提炼）

1. **台词短、狠、有力**：不说废话，每句台词推动冲突或揭示信息
2. **动作具体可拍**：写"抬脚踹向残肢伤口"，不写"攻击了她"
3. **情绪外化为身体反应**：不写"她很愤怒"，写"爪尖掐破掌心""指甲嵌进掌心，伤口渗血"
4. **信息差制造悬念**：观众知道但角色不知道的信息（如Ivy口袋里的镇静剂），制造追看欲
5. **每集结尾高能收束**：
   - 第1集结尾：Garrick瞬移现身展露强大力量 + 继母认出天狼尊主
   - 第2集结尾：Evie出现复苏迹象 + 女主VO预告真相将揭露
   - 第3集结尾：天狼尊主身份当众曝光，全员震惊
6. **VO 用于关键内心转折**：只在主角做出重大决策、预判局势时使用，不做流水账解说
7. **场景间节奏对比**：虐→爽→甜拉扯交替，不要连续三场同一情绪
8. **反派不脸谱化**：每个反派有自己的动机和行为逻辑（Lester护权、Helena护女、Ivy求存、Darien护妹）

## 对标参考

本样稿对标：《出狱当天，世间再无我》
- 蒙冤出狱 + 全员恶人原生家庭 + 独立取证复仇 + 神秘强者守护
- 核心结构：冤屈建置 → 归家受虐 → 暗中取证 → 真相揭露 → 终极审判
