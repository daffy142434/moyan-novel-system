# 剧情地图模板

## 格式说明

剧情地图是改编的核心中枢文档，将小说原文拆解为可执行的剧情点，并标注分集归属。采用批次追加模式，每批处理6章。

---

## 文档头部（首次创建时写入）

```markdown
# 《[书名]》剧情地图

## 基本信息
- 题材类型：[类型]
- 目标模式：[短剧/动态漫]
- 预计集数：[根据拆解动态更新]

## 角色索引
| 角色 | 身份 | 核心特征 | 称呼规范 |
|------|------|---------|---------|
| [主角名] | [表面身份]/[隐藏身份] | [2-3个关键词] | 自称X/被称X |
| [反派名] | [身份] | [关键词] | 被称X |

---
```

## 批次内容格式

```markdown
## 批次 N：第X章 ~ 第X章

### 【剧情01】[一句话概括]
- **场景**：[地点/时间]
- **角色**：[出场人物]
- **事件**：[2-3句描述核心事件]
- **钩子类型**：[💥爽点释放 / 🔨压力蓄积 / 💔情感冲击 / ❓悬念牵引 / 🔥燃点激发]
- **冲突强度**：[S/A/B/C/D]
- **归属集数**：EP-[XX]
- **原著章节**：第X章（第X页~第X页）
- **状态**：[待用 / 已用]

### 【剧情02】[一句话概括]
...（同上格式）

---

### 批次小结
- 本批提取剧情点：X 个
- 新增集数标注：EP-XX ~ EP-XX
- 关键角色变化：[记录]
- 新增伏笔：[内容 → 计划EP-XX回收]
```

## 格式强制规则

1. 剧情点编号全局递增，不重置（批次1的剧情01-12，批次2从剧情13开始）
2. 每个剧情点**必须**包含所有字段，不可省略
3. 钩子类型和冲突强度必须使用规定的标记
4. 状态字段初始为「待用」，创作剧本后更新为「已用」
5. 归属集数在拆解时标注，后续可根据实际创作调整
6. 角色索引在发现新角色时追加更新
