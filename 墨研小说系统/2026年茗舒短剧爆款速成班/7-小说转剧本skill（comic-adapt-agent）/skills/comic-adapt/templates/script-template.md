# 单集剧本模板

## 格式规范

```markdown
剧名：《[剧名]》
集数：EP-[XX]  [集标题]
模式：[短剧/动态漫]
对应剧情点：【剧情XX】~【剧情XX】
原著章节：第X章 ~ 第X章
情绪类型：[💥/🔨/💔/❓/🔥]
情绪强度：[X]/10

════════════════════════════════════════

场次 [集数]-1：[内/外]  [具体地点]  [日/夜]
────────────────────────────────────────
出场人物：[角色1]；[角色2]

△ （[景别]）[场景/动作描写，不超过3行]

[角色名]
（[语气/动作指示]）
[台词正文]

△ （[景别]）[角色反应或动作]

[角色名]
（[语气/动作指示]）
[台词正文]

────────────────────────────────────────

场次 [集数]-2：[内/外]  [具体地点]  [日/夜]
────────────────────────────────────────
出场人物：[角色N]

△ （[景别]）[场景描写]

......

════════════════════════════════════════

【卡黑】

下集预告：[一句话悬念钩子]
```

## 格式强制规则

1. **场景头**：`场次 [集数]-[序号]：[内/外]  [地点]  [日/夜]`，三要素缺一不可
2. **出场人物**：每个场次必须列出，分号分隔
3. **△ 描写**：每段不超过3行，必须标注景别，使用动态动词
4. **台词结构**：角色名→括号指示→台词正文，三行结构强制
5. **台词长度**：短剧 ≤25字/句，动态漫 ≤35字/句
6. **结尾**：必须以【卡黑】结束，附下集预告
7. **字数范围**：短剧 500-800字，动态漫 800-1200字
8. **场次数**：短剧 2-4个，动态漫 3-5个

## 特殊标记使用规范

- `※` 用于特殊视觉效果：`※ 金光暴涨，整个大殿震动`
- `【旁白】` 用于画外音：`【旁白】三年前的那个夜晚，改变了一切。`
- `【字幕】` 用于时间/地点跳转：`【字幕：三天后 / 京城】`
- `♪` 用于音乐提示：`♪ 低沉压抑的配乐渐起`
- `☎` 用于通讯：`☎ 手机屏幕亮起——来电显示：未知号码`
