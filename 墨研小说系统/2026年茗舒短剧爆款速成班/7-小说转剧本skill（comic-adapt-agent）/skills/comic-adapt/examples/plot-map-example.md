## 批次 1：第1章 ~ 第6章

### 【剧情01】破旧出租屋的结婚纪念日
- **场景**：破旧出租屋 / 夜
- **角色**：陈锋、林小雨
- **事件**：结婚三周年，陈锋用微薄积蓄买了小蛋糕，两人温馨但心酸。林小雨接到林母电话，通知明天必须参加家宴。陈锋沉默后答应。
- **钩子类型**：🔨压力蓄积
- **冲突强度**：C
- **归属集数**：EP-01
- **原著章节**：第1章
- **状态**：待用

### 【剧情02】林家豪宅的公开羞辱
- **场景**：林家豪宅客厅 / 日
- **角色**：陈锋、林小雨、林母、林浩天、赵倩、林家亲属
- **事件**：林母当众嫌弃陈锋穷酸，林浩天嘲笑逼他下跪，赵倩提出让林小雨嫁给赵家公子。全场嘲笑。陈锋一言不发承受所有羞辱。
- **钩子类型**：🔨压力蓄积
- **冲突强度**：A
- **归属集数**：EP-01
- **原著章节**：第1章~第2章
- **状态**：待用

### 【剧情03】神秘来电——龙主时候到了
- **场景**：林家豪宅客厅 / 日
- **角色**：陈锋
- **事件**：所有人嘲笑的最高潮，陈锋手机震动，屏幕显示「龙主，时候到了」。陈锋抬头，嘴角冷笑：「三年期满，该还的一分不少。」
- **钩子类型**：❓悬念牵引
- **冲突强度**：S
- **归属集数**：EP-01
- **原著章节**：第2章
- **状态**：待用

### 【剧情04】龙组副手当众跪拜
- **场景**：林家豪宅大门外 / 日
- **角色**：陈锋、林小雨、林母、林浩天、赵倩、黑衣人×12
- **事件**：十二名黑衣人列队出现，为首者单膝跪地：「龙主，三年之约已满，请回归。」全场死寂。林浩天的雪茄掉在地上。林母腿软。
- **钩子类型**：💥爽点释放
- **冲突强度**：S
- **归属集数**：EP-02
- **原著章节**：第3章
- **状态**：待用

### 【剧情05】陈锋身份初揭——林家震动
- **场景**：林家豪宅客厅 / 日
- **角色**：陈锋、林母、林浩天
- **事件**：陈锋换上黑色正装，气场全变。林母颤声道歉，林浩天跪地求饶。陈锋只看向林小雨：「走吧，这里不配留你。」
- **钩子类型**：💥爽点释放
- **冲突强度**：A
- **归属集数**：EP-02
- **原著章节**：第3章~第4章
- **状态**：待用

### 【剧情06】赵家上门威胁——新势力登场
- **场景**：陈锋新住所 / 夜
- **角色**：陈锋、林小雨、赵家管家
- **事件**：赵家管家送来威胁信：三天内交出林小雨，否则陈锋和林家同归于尽。陈锋看完信，淡淡一笑：「赵家？排不上号。」
- **钩子类型**：🔨压力蓄积
- **冲突强度**：B
- **归属集数**：EP-03
- **原著章节**：第5章~第6章
- **状态**：待用
