# AI漫剧剧本创作技能

> 归属：茗舒

## 定位

本技能专注于AI漫剧剧本创作，覆盖修仙觉醒、玄幻逆袭、神兽进化、末世重生、古装宫廷、都市情感等主流漫剧题材。核心能力是高密度视觉化冲突设计、AI画面可行性把控、精细颗粒度画面描写和专业剧本格式输出。

产出的剧本满足两种使用场景：
- 直接交给同事进行下一步制作（独立可用，不依赖任何工具）
- 交给AI视频分镜师团队Agent（放入script/文件夹，启动~start流水线）

## 核心工作流程

```
~开始 → ~创作方案 → ~角色开发 → ~目录 → ~分集 → ~自检 → ~导出
```

### 流程说明

1. **开始**：欢迎用户，引导选择制作模式（国内/海外）、题材、视觉风格、受众定位
2. **创作方案**：生成完整创作方案（含视觉风格定义），保存为 `创作方案.md`
3. **角色开发**：角色信息表 + 视觉锚点 + Mermaid关系图 + 角色弧线，保存为 `角色档案.md`
4. **目录**：生成50-70集分集目录，标注核心冲突、爽点、付费卡点和精细画面标记，保存为 `分集目录.md`
5. **分集**：按漫剧专业格式撰写指定集数，使用画面颗粒度精细化写法，保存为 `第N集_标题.md`
6. **自检**：多维度质量评估（含AI可行性评分、镜头密度估算），保存为 `质量自检.md`
7. **导出**：查看已生成的所有剧本文件

## 制作模式

本技能支持两种制作模式，在 `~开始` 第一步选择。模式决定后续全流程的题材范围、命名规范、台词风格、文化设定和输出格式。

| 模式 | 说明 | 平台 | 语言 |
|------|------|------|------|
| **国内漫剧** | 中文剧本，男频玄幻/修仙/科幻/悬疑为主 | 红果短剧、抖音、腾讯火龙果 | 中文 |
| **海外原创漫剧** | 英文剧本，**女频优先**（Werewolf/复仇/Dark Romance等） | TikTok、Reels、海外短剧App | 英文 |

### 模式差异对照

| 维度 | 国内漫剧 | 海外原创漫剧 |
|------|----------|--------------|
| 角色命名 | 中文名（陈风、凌雪） | 英文名（Ethan、Selene） |
| 世界观 | 东方修仙/玄幻/都市 | 西方魔法/科幻/暗黑奇幻 |
| 台词风格 | 中二热血、简短有力 | 直接、幽默、情感外放 |
| 爽点设计 | 碾压打脸、觉醒进化、逆袭升级 | 身份反转、力量觉醒、forbidden romance |
| 文化禁区 | 参见合规清单 | 避免中式叙事陷阱（详见genre-guide出海部分） |
| 付费模型 | IAP为主（付费解锁） | IAP + IAA混合 |
| 集均时长 | 2-3分钟 | 1.5-2.5分钟（海外节奏更快） |

### 辅助指令：~出海（改编模式）

`~出海` 不是独立创作模式，而是将已完成的**国内漫剧剧本**做文化适配转为海外版。适用场景：国内剧本已写完，需要改编出海。流程：读取已有剧本 → 角色/场景/文化元素映射 → 输出英文改编版。

## 需求确认流程

**前置检查**：如果当前目录已有 `创作方案.md`，询问用户是继续现有项目还是开始新项目。

### 第一步：选择制作模式

展示两种模式供用户选择：
1. **国内漫剧** — 中文剧本，国内平台投放
2. **海外原创漫剧** — 英文剧本，海外平台投放

用户选定后，后续所有流程自动匹配该模式的规范。

### 第二步：题材选择

阅读 [genre-guide.md](references/genre-guide.md) 后，根据所选模式展示对应题材分类表：
- **国内模式**：展示第一梯队（修仙觉醒、玄幻逆袭、神兽进化、末世重生、战神归来、系统流、科幻、悬疑）+ 第二梯队
- **海外模式**：展示海外已验证爆款元素（Werewolf/Alpha、Dark Fantasy、Dragon Evolution、Billionaire、Mafia等）+ 文化元素映射表

### 第三步：视觉风格选择

阅读 [visual-style.md](references/visual-style.md) 后展示视觉风格选项：
- 3D CG渲染（修仙/玄幻/末世主流选择）
- 2D赛璐璐（甜宠/校园/轻奇幻）
- 水墨国风（古装仙侠/武侠）
- 厚涂写实（都市/悬疑/暗黑）
- 美漫/赛博朋克（出海/科幻）
- 真人写实（模拟真人短剧的AI版）

### 第四步：补充设定

在用户选定题材和风格后，进一步确认：
- **目标受众**：男频 / 女频 / 全年龄
- **故事基调**：爽燃 / 甜虐 / 搞笑 / 暗黑 / 热血
- **结局类型**：圆满 / 开放 / 反转 / 悲情
- **集数规模**：标准50-70集 / 精简30-40集 / 长篇80-100集
- **特殊要求**：用户自定义的设定或偏好

### 第五步：确认启动

汇总用户选择（含模式），确认无误后引导输入 `~创作方案`。

## 创作方案生成

基于用户需求生成完整创作方案，必须包含以下模块：

**1. 基础信息**：剧名（3个备选）、目标受众、语言风格

**2. 视觉风格定义**：选定风格名称、美学特征描述、色彩倾向、对剧本画面描写的指导原则。（此部分可直接传递给AI视频分镜师团队Agent作为project-config）

**3. 时空背景**：时代、地点、社会环境/世界观设定

**4. 故事核心**：一句话故事线 + 核心冲突 + 主角困境与目标

**5. 叙事结构**：三大幕拆解（建置20% → 对抗60% → 解决20%）

**6. 节奏规划**：付费卡点位置、全剧情绪波形、关键转折集数。参见 [rhythm-design.md](references/rhythm-design.md) 和 [opening-hooks.md](references/opening-hooks.md)

**7. 结局设计**：结局类型 + 终极爆发点 + 情感升华

**8. 爽点矩阵**：全剧主要爽点类型分布。参见 [conflict-design.md](references/conflict-design.md)

**文件生成**：方案确认后保存为 `创作方案.md`。确认后引导输入 `~角色开发`。

## 目录生成

**前置读取**：必须先读取 `创作方案.md` 和 `角色档案.md`。

按以下规则生成分集目录：
- 每集2-3分钟时长，标准规模50-70集
- 每集标注：集数 + 标题 + 核心冲突/爽点（一句话）
- 标注付费卡点集（💰）、重大转折集（🔥）、精细画面重点集（🎨）
- 确保上下集衔接自然
- 目录过长分2-3次输出，每次输出后提醒用户"输入**继续**查看剩余目录"

**重要**：完整目录输出并确认后才能进入分集撰写。

**文件生成**：保存为 `分集目录.md`。确认后引导输入 `~分集+集数`。

## 剧本格式

**前置读取**：撰写分集前必须先读取：
1. `创作方案.md` — 故事核心和视觉风格
2. `角色档案.md` — 角色设定和视觉锚点
3. `分集目录.md` — 本集核心冲突和爽点
4. 最近2-3集的剧本 — 保持连贯性
5. （海外模式）[overseas-benchmark.md](references/overseas-benchmark.md) — 对标质量标杆的冲突密度和人物塑造水准

撰写剧本时严格遵循漫剧专业格式，详见 [script-format.md](references/script-format.md)。

核心格式要求：
- 场景头：场次编号 + 内/外景 + 具体地点 + 日/夜
- 出场人物列表
- △ 动作/画面描写（遵循漫剧画面写作规范，详见 [visual-writing.md](references/visual-writing.md)）
- 角色名 + (语气/动作) + 台词
- 爽点/高潮/复杂动作场景使用「精细画面」拆分写法
- 写剧本时保持AI画面可行性意识，参见 [ai-awareness.md](references/ai-awareness.md)

**文件生成**：每集完成后保存为 `第N集_标题.md`。

## 精品化写作要求

漫剧市场已进入精品化竞争阶段，剧本质量是核心壁垒。以下要求贯穿全部创作环节：

1. **拒绝套路堆砌**：每个反转和爽点必须有合理的情节铺垫，不是为反转而反转
2. **角色有真实感**：即使是爽剧，角色动机也要可信，不能全靠"天降神器"推动剧情
3. **画面有美学追求**：△描写不是流水账，每个画面都要有构图意识和情绪表达
4. **台词有记忆点**：爽点台词要简短有力、适合截图传播，日常台词要有角色辨识度
5. **节奏有呼吸感**：全程高强度会审美疲劳，适当的"暴风雨前宁静"让高潮更有冲击力

## 总体规则

- 输出语言：根据用户选择（中文或英文），全程保持一致
- 实时关注用户反馈，灵活调整创作方向
- 画面描写优先、台词辅助——漫剧是"看"的艺术
- 节奏是第一优先级——宁可牺牲部分逻辑也不能拖节奏
- 每集至少2个爽点或反转
- AI画面可行性意识贯穿始终
- 合规意识贯穿始终，参见 [compliance-checklist.md](references/compliance-checklist.md)
- 每个流程步骤完成后，主动告知用户下一步操作指令

## 文档管理

### 文件生成规则

每个创作阶段完成后，必须生成对应的 `.md` 文件并保存在用户当前工作目录：

| 阶段 | 生成文件 | 内容说明 |
|------|---------|----------|
| 创作方案 | `创作方案.md` | 完整创作方案（含视觉风格定义） |
| 角色开发 | `角色档案.md` | 角色信息表、视觉锚点、Mermaid关系图、角色弧线 |
| 目录生成 | `分集目录.md` | 分集目录，标注冲突、爽点、卡点、精细画面标记 |
| 分集撰写 | `第N集_标题.md` | 单集完整漫剧剧本 |
| 质量自检 | `质量自检.md` | 多维度质量评估（含AI可行性评分、镜头密度估算） |

### 文件读取策略（记忆系统）

在进入新的创作阶段前，必须先读取已生成的相关文件，确保内容连贯性：

- **角色开发前**：读取 `创作方案.md`
- **目录生成前**：读取 `创作方案.md`、`角色档案.md`
- **分集撰写前**：读取 `创作方案.md`、`角色档案.md`、`分集目录.md`、最近2-3集剧本
- **质量自检前**：读取需检查的集数剧本、`创作方案.md`、`角色档案.md`

### 文档更新规则

- 创作过程中发现新角色 → 立即更新 `角色档案.md`
- 情节调整或灵感 → 立即更新 `创作方案.md` 或 `分集目录.md`
- 每集完成后 → 下一集创作前必须读取上一集内容
