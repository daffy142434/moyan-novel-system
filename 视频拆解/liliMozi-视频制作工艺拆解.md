# liliMozi 视频制作工艺拆解

> 目标：只拆视频是怎么做出来的，不分析视频观点内容。
>
> 来源：用户提供的抖音单条视频链接。已去重后共 7 条唯一视频。

## 总体结论

这个博主的视频不是单一制作方式，而是三套模板混用：

1. AI 动画剧情 + 知识讲解
2. 真实网页/工具演示 + 动画包装
3. 长视频 PPT 化叙事 + 插画角色 IP

通用生产链路大致是：

```text
文案脚本
-> 分镜拆段
-> 固定角色 AI 生图
-> 局部图生视频或轻动画
-> 网页/文档/论文/聊天截图卡片化
-> 剪映 / Premiere / After Effects 做转场、字幕、推拉镜头
-> 配音、音乐、音效
-> 发布
```

他最核心的能力不是单纯会用 AI 视频工具，而是：

```text
会做产品/网页/Skill
会写长脚本
会用稳定角色做视觉 IP
会把截图包装成动画卡片
会用剪辑把技术内容做成故事
```

## 统一视觉特征

### 角色 IP

视频中反复出现同一类角色：

- 黑发、圆框眼镜、紫色挑染的女孩
- 蓝色小鲸鱼或其他拟人吉祥物
- 蓝发女性角色
- 少量同事、老师、家人、路人角色

这些角色用于承担“讲解人”“陪伴者”“产品使用者”“故事主角”的功能。

制作方式大概率是：

```text
先生成角色参考图
-> 后续每个镜头用相同角色描述或参考图生成
-> 少量镜头用图生视频做眨眼、推镜、手部动作
-> 后期统一色调和字幕样式
```

### 画面类型

常见画面可以分成 5 类：

```text
1. AI 插画场景：书房、课堂、办公室、校园、客厅
2. 产品界面：网页工具、聊天界面、配置页面、代码页面
3. 文档材料：论文截图、网页文章、表格、Skill 文件
4. 概念图：手绘图、黑板、流程图、示意卡片
5. 真实素材：新闻截图、演讲截图、社媒截图
```

### 后期手法

常用后期手法：

```text
推镜头
横向滑动
卡片飞入
截图放大
白场过渡
景深虚化
运动模糊
大字幕压底
章节标题卡
```

这类视频多数不是“全程 AI 视频生成”，而是“静态素材 + 轻动画 + 剪辑调度”。

## 视频 1：全国大学信息炼化成 Skill

链接：`https://v.douyin.com/z_uLw_Pnov4/`

作品 ID：`7654982193281912102`

规格：

```text
横屏 1280x720
约 285 秒
```

### 类型判断

这是 **动画剧情 + 文档/网页卡片 + 产品说明片**。

不是纯录屏，也不是纯 AI 动画。它的结构是：先用角色和故事建立情境，再插入真实或半真实的 Skill/文档/网页展示。

### 画面结构

大致结构：

```text
0-30 秒：餐馆/校园/人物对话式开场
30-90 秒：角色讲解 + 概念铺垫
90-140 秒：书房角色讲解 + 白底界面转场
140-200 秒：真实文档、聊天界面、表格或网页截图
200-250 秒：角色继续解释 Skill 使用方式
250-285 秒：校园建筑、复古电脑、抖音搜索页收尾
```

### 素材来源推断

```text
AI 生图：餐馆、校园、书房、人物角色、校园建筑
截图素材：Skill 文件、大学资料卡、聊天界面、文档页面
后期合成：卡片入场、界面放大、字幕、转场
```

### 制作方法

1. 先准备一个大学信息 Skill 或资料库。
2. 写一个 4-5 分钟脚本，拆成故事段和演示段。
3. 为故事段生成 AI 插画分镜。
4. 为演示段准备真实网页、文档、聊天界面截图。
5. 在剪辑软件里把截图做成漂浮卡片、缩放、横移。
6. 加底部字幕和配音。

### 复刻重点

```text
真实资料库/Skill 是可信度来源
AI 角色和校园场景是包装
截图卡片动画是连接两者的桥
```

## 视频 2：如何让豆包做到真正直白一针见血

链接：`https://v.douyin.com/LC7jsqLDia0/`

作品 ID：`7658121161846345014`

规格：

```text
竖屏 720x1280
约 127 秒
```

### 类型判断

这是 **AI 角色短片包装的软件教程**。

它不是传统录屏教程，而是把豆包/网页/文档截图包装成动画短片。

### 画面结构

大致结构：

```text
0-8 秒：女孩举 HTML + AI 牌子，强钩子
8-25 秒：书房角色讲解，建立主题
25-75 秒：豆包/网页/提示词截图以卡片形式出现
75-105 秒：网页、文档、项目页等素材卡片切换
105-125 秒：课堂/角色/代码世界镜头收尾
```

### 素材来源推断

```text
AI 生图：女孩角色、书房、课堂、代码世界
真实截图：豆包界面、网页 Demo、文章页面、项目页面
后期合成：截图卡片滑入、虚化背景、镜头推拉
```

### 制作方法

1. 写一个 120 秒以内的口播文案。
2. 把文案拆成 8-12 个镜头。
3. 为每个镜头生成统一角色插画。
4. 把豆包、网页、文档页面截图导出。
5. 在剪映或 AE 中做卡片运动。
6. 加字幕、配音、轻音乐。

### 复刻重点

```text
截图不能直接硬切，要卡片化
角色要统一
每 5-8 秒必须有画面变化
```

### 类型判断

这是 **固定虚拟主播/插画主持人 + 字幕长讲解**。

相比其他几条，它的运动复杂度更低，更像“播客讲解视频”或“单镜头虚拟主播讲解”。

### 画面结构

已抽帧显示：

```text

主体：固定插画主播坐在沙发前讲解

```

### 素材来源推断

```text
固定角色图：AI 生成或绘制
背景图：AI 插画/固定场景
字幕：自动识别后手动校对
开头素材：影视/真实素材引用
```

### 复刻重点


## 可复刻制作流水线

如果要按这个博主风格批量做视频，可以这样组织：

### 第一步：确定视频类型

```text
产品发布型：真实 demo + 动画剧情
知识科普型：章节卡 + 资料截图 + 角色串场
教程复刻型：软件截图 + 卡片动效 + 竖屏短视频
```

### 第二步：写脚本

脚本建议分成：

```text
钩子
背景
问题
演示
解释
结果
总结
```

### 第三步：拆分镜

每 6-12 秒一个镜头：

```text
镜头编号
画面内容
素材类型
字幕重点
是否需要 AI 生图
是否需要真实截图
转场方式
```

### 第四步：准备素材

素材清单：

```text
固定角色图
吉祥物图
书房/课堂/办公室背景
产品网页截图
聊天截图
论文/文档截图
手绘概念图
章节标题卡
```

### 第五步：生成动画

推荐方式：

```text
AI 生图：豆包、即梦、Midjourney、Stable Diffusion
图生视频：MiniMax、可灵、即梦、Runway、Pika、Luma
截图动效：剪映、Premiere、After Effects
网页演示：浏览器录屏、OBS、Playwright、Remotion
```

### 第六步：剪辑

剪辑原则：

```text
每 5-10 秒有视觉变化
截图不要硬放，要卡片化
角色镜头和信息镜头交替
底部字幕统一样式
章节标题承担节奏重置
```

## 工具建议

### 入门版

```text
豆包/即梦：生图
MiniMax/可灵：图生视频
剪映专业版：剪辑、字幕、配音、转场
Chrome/OBS：录制网页
```

### 进阶版

```text
Midjourney/Stable Diffusion：稳定角色
After Effects：卡片动效、景深、运动模糊
Premiere：长视频剪辑
Remotion：程序化视频和网页录制
Figma：界面和卡片排版
```

### 产品 Demo 型

```text
Next.js / Vite / React：做真实网页工具
Tailwind CSS：快速搭 UI
LLM API：生成 AI 功能
OBS / Playwright：录制演示
```

## 难度排序

从容易到困难：

```text
1. 固定主播长讲解
2. 手绘风知识卡片
3. 竖屏 AI 动画教程
4. 横屏长科普电影化
5. 真实产品 Demo + 动画剧情包装
```

最难的不是视频工具，而是：

```text
脚本结构
角色一致性
真实 demo 准备
长视频节奏控制
素材风格统一
```

## 最值得学习的地方

如果只学 5 个点：

1. 固定一个角色 IP，让观众形成记忆。
2. 每条视频先写完整分镜，不要边剪边想。
3. 做真实 demo 或至少真实截图，提高可信度。
4. 把截图变成卡片动效，不要直接录屏硬切。
5. 用章节标题、角色镜头、资料截图交替控制节奏。

## 后续可继续拆解的方向

下一步可以继续做更细版本：

```text
逐视频秒级分镜表
每条视频素材清单
每条视频复刻提示词
每条视频剪映/AE 工程结构
这个博主的标准生产 SOP
```
