# TikTok 视频下载器 — 可行性报告

> 日期：2026-07-16

---

## 1. 结论

**可行。** 基于 `yt-dlp` 开源项目，可在 Windows 命令行下直接下载 TikTok 视频，并具备封装为独立工具的基础。

## 2. 技术验证

### 2.1 核心工具：yt-dlp

|------|------|

| 工具 | 状态 |

### 2.3 下载流程

```
用户提供 TikTok URL
        ↓
yt-dlp 解析页面 → 提取视频直链 → 下载到本地
        ↓
输出 MP4 文件
```

## 3. 可实现的产品方案

### 方案 A：CLI 命令行工具（最快落地）

直接包装 `yt-dlp`，提供简单命令，如：

```bash
tiktok-dl https://vm.tiktok.com/xxxxxx
```

### 方案 B：Python GUI 桌面工具

使用 PyQt6 / Tkinter 做图形界面：
- 粘贴链接 → 选择目录 → 下载
- 支持批量下载（用户主页、合集）
- 下载进度条
- 无水印选项

### 方案 C：Android App

调用 `yt-dlp` 的 Python API 或封装为 Android 可执行文件：
- 分享到 App 自动下载
- 下载管理
- 本地视频库

## 4. 局限性

| 限制 | 说明 |
|------|------|
| 无水印 | yt-dlp 默认下载的是 TikTok 官方提供的视频流，可能带水印。完全去水印需额外处理 |
| 反爬变化 | TikTok 不定期更新反爬机制，yt-dlp 依赖社区更新维护 |
| 法律合规 | 下载他人作品用于再发布可能涉及版权问题，仅供个人收藏 |
| ffmpeg | 下载含音频分离的视频时需要 ffmpeg（当前系统无） |

## 5. 推荐路线

1. **先做 CLI 版本**（即刻可用）
2. **再包装 GUI**（降低使用门槛）
3. **可选打包为独立 exe**（无需 Python 环境）
