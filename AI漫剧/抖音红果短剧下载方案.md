## 二、阶段一：从第一集链接找到全集并下载

### 2.1 抖音短剧场景

```
用户给链接 → 识别合集ID → 获取全集列表 → 批量下载

流程：
1. 第一集链接 → 解析出作者ID + 合集ID（或作品ID）
2. 调用合集API获取该合集下所有视频列表
3. 按集排序，批量下载
```

**推荐实现方式：F2（Python 库方式调用）**

```python
# 伪代码示例
from f2.apps.douyin.handler import DouyinHandler

handler = DouyinHandler()
# 从第一集链接提取合集ID
mix_id = handler.get_mix_id_from_video(video_url)
# 获取合集所有视频
videos = handler.fetch_user_mix_videos(mix_id)
# 批量下载
for video in videos:
    handler.download_video(video, watermark=False)
```

### 2.2 红果短剧场景

```
用户给链接 → 识别短剧ID → 获取所有集列表 → 批量下载
```

**推荐实现方式：short-drama-downloader**
- 已有搜索+批量下载功能
- 输入短剧首页链接即可提取所有集
- 或直接通过短剧ID下载全集

### 2.3 yt-dlp 备选方案（quick & dirty）

```bash
# 抖音合集下载
yt-dlp --cookies cookies.txt \
  -f "bestvideo+bestaudio/best" \
  -o "./douyin_%(playlist_title)s/%(playlist_index)02d_%(title)s.%(ext)s" \
  -I 1:ALL \
  "https://www.douyin.com/collection/xxxxx"
```

**限制**：yt-dlp 需要手动找到合集链接，无法从单集反推合集。

## 三、阶段二：爬取目录 + 数据库索引 + 按需下载

### 3.1 架构设计

```
┌─────────────────┐     ┌─────────────┐     ┌───────────┐
│  爬虫引擎        │ →   │  数据库      │ →   │  下载队列  │
│  - 抖音分类爬取  │     │  SQLite/Mongo│     │           │
│  - 红果搜索爬取  │     │  - 剧名      │     │  - 待下载  │
│  - 全网聚合      │     │  - 分类      │     │  - 下载中  │
│                 │     │  - 集数      │     │  - 已完成  │
│                 │     │  - 链接      │     │  - 失败    │
│                 │     │  - 状态      │     │           │
└─────────────────┘     └─────────────┘     └───────────┘
        │                                           │
        ▼                                           ▼
  定时任务(可选)                               存储系统
                                              磁盘/NAS
```

### 3.2 数据库模型设计

```sql
-- 短剧主表
CREATE TABLE dramas (
    id VARCHAR(64) PRIMARY KEY,          -- 短剧唯一ID
    title VARCHAR(255),                   -- 剧名
    category VARCHAR(100),                -- 分类/类型
    author VARCHAR(255),                  -- 作者
    total_episodes INT,                   -- 总集数
    description TEXT,                     -- 简介
    cover_url TEXT,                       -- 封面
    platform VARCHAR(50),                 -- 来源平台(抖音/红果)
    source_url TEXT,                      -- 来源链接
    created_at DATETIME,
    updated_at DATETIME
);

-- 单集表
CREATE TABLE episodes (
    id VARCHAR(64) PRIMARY KEY,           -- 视频ID
    drama_id VARCHAR(64),                 -- 所属短剧
    episode_num INT,                      -- 第几集
    title VARCHAR(255),                   -- 单集标题
    video_url TEXT,                       -- 视频链接
    duration INT,                         -- 时长(秒)
    download_status INT DEFAULT 0,        -- 0未下载/1下载中/2已完成/3失败
    file_path TEXT,                       -- 本地文件路径
    created_at DATETIME
);

-- 分类表
CREATE TABLE categories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),                    -- 分类名
    platform VARCHAR(50)                  -- 所属平台
);

-- 下载任务表
CREATE TABLE download_tasks (
    id INT AUTO_INCREMENT PRIMARY KEY,
    drama_id VARCHAR(64),                 -- 短剧ID
    priority INT DEFAULT 0,              -- 优先级
    status INT DEFAULT 0,                -- 0排队/1下载中/2完成/3失败
    created_at DATETIME,
    completed_at DATETIME
);
```

### 3.3 分类爬取策略

| 平台 | 爬取方式 | 难点 | 方案 |
|------|---------|------|------|
| **红果短剧** | 搜索接口爬取 | 需逆向APP接口或用selenium | short-drama-downloader已有现成搜索功能，可直接复用 |
| **抖音短剧** | 搜索关键词爬取 | 反爬策略严格，需cookie | 使用F2的搜索能力，模拟用户搜索 |
| **全网聚合** | 多来源聚合 | 需去重 | 以剧名+作者为唯一键去重 |

### 3.4 搜索→确认→下载流程

```
1. 爬虫定期跑 → 爬取各平台短剧信息
2. 存入 dramas 表和 episodes 表（含链接，不下载视频）
3. 前端/搜索界面 → 用户搜索剧名/分类
4. 用户选择要下载的短剧
5. 创建下载任务 → 进入队列
6. 下载器按队列逐集下载 → 状态更新
7. 完成后通知用户
```

## 四、推荐技术栈

| 组件 | 技术选型 | 理由 |
|------|---------|------|
| 语言 | Python 3.10+ | 生态最全，所有开源工具都是Python |
| 下载核心 | F2 + short-drama-downloader | 现成方案，节约开发时间 |
| 数据库 | SQLite（单机）/ MySQL（服务端） | 轻量级用SQLite，多端用MySQL |
| 异步框架 | asyncio + aiohttp | 提高爬取和下载效率 |
| 界面（可选） | Gradio / Streamlit | Python快速搭建Web界面 |
| 任务队列 | Redis + RQ / Celery | 多任务并发管理 |

## 五、各方案优缺点对比

| 方案 | 开发量 | 抖音支持 | 红果支持 | 全集自动发现 | 数据库索引 | 维护成本 |
|------|--------|---------|---------|------------|-----------|---------|
| **纯 yt-dlp 脚本** | 低（1-2天） | ✅ | ❌ | ❌需手动找合集 | ❌ | 低 |
| **F2 + short-drama-downloader** | 中（3-5天） | ✅ | ✅ | ✅ | ❌需自己加 | 中 |
| **全自研爬虫** | 高（2周+） | ⚠️被反爬 | ⚠️被反爬 | ✅ | ✅ | 高 |
| **⭐ 推荐：F2 + short-drama-downloader + 自研数据库层** | 中（5-7天） | ✅ | ✅ | ✅ | ✅ | 中 |

## 六、推荐路线

### 第一阶段（快速可用）
```
1. 用 F2 实现抖音单剧下载
2. 用 short-drama-downloader 实现红果短剧下载
3. 写一个简单的 CLI 脚本：输入链接 → 自动下载全集
```

### 第二阶段（完善）
```
4. 建 SQLite 数据库
5. 写爬虫脚本搜索各平台短剧目录
6. 搜索结果入库
7. 提供搜索查询 + 选择下载
```

### 第三阶段（体验优化）
```
8. 搭建 Web 界面（搜索→浏览→点击下载）
9. 定时自动爬取更新
10. 下载进度管理
```

## 七、风险提示

| 风险 | 说明 |
|------|------|
| ⚠️ **版权问题** | 短剧有版权，下载仅限个人学习/备份，勿商用或二次分发 |
| ⚠️ **反爬策略** | 抖音和红果会更新反爬措施，工具需要持续维护更新 |
| ⚠️ **封号风险** | 频繁操作可能导致抖音账号被限流/封禁 |
| ⚠️ **链接失效** | 短剧可能下架，视频链接有有效期 |
| ⚠️ **工具变更** | F2/short-drama-downloader 可能停止维护 |
