# 《长生客栈》3D AI漫剧全局画面基准

> 版本：V1·项目强制标准  
> 适用：角色、场景、反派、群演、机关、道具、特效、分镜图、图生视频及后期合成  
> 优先级：本文件是视觉总纲。其他文档若出现“二维、线稿、平面色块、旅行绘本”等旧表述，以本文件为准。

配套生产卡：人物使用`AI角色视觉生产卡.md`，环境使用`AI场景视觉生产卡.md`，敌对角色与群众使用`AI反派与群演视觉生产卡.md`，机关、关键道具和末法特效使用`AI机关道具特效生产卡.md`。

## 一、最终画面定位

《长生客栈》统一制作成**竖屏东方幻想3D动画漫剧**：清透明亮、风格化半写实、人物美型但保留年龄与职业差异，环境具有可触摸的木、石、布、水材质，法术规模极小，整体更接近连续剧式动画电影镜头，而非游戏录屏、真人换脸或二维动态漫画。

### 五个固定关键词

1. 东方古风旅行生活感。
2. 高品质风格化3D半写实。
3. 明亮清透、冷暖互补。
4. 轻喜表演与细腻情感同框。
5. 末法时代的克制微光，不做满屏仙术。

### 明确排除

- 灰黄废土、长期风沙、苦旅脏滤镜。
- 二维插画、厚描边、平面赛璐璐、漫画网点。
- 真人摄影、真人换脸、过度毛孔与恐怖谷。
- 塑料手办、盲盒Q版、低模手游、游戏UI与引擎编辑界面。
- 华丽修仙宫殿、御剑飞行、巨大法阵、光翼、满屏灵气粒子。

## 三、3D造型与材质基准

### 人物

- 主角约7—7.5头身，少年阿九可略低但不Q版；同框依靠身高、肩宽、发型和道具形成剪影差。
- 面部为动画化东方骨相：眼睛略作美型，不超现实放大；鼻唇体积完整，侧脸可成立。
- 皮肤保留轻微粗糙度与年龄差，只做克制次表面散射；禁止瓷白、果冻脸和强油光。
- 发型按“大束轮廓＋少量前额碎发”制作，避免大量独立细发造成视频闪烁。
- 服装最多三层主结构、两种主材质、一个固定点色；满绣、透明薄纱和连续流苏只作小面积点缀。

### 材质表

| 材质 | 3D表现 | 禁止 |
|---|---|---|
| 棉麻 | 中等粗糙度、细织纹、折痕清楚 | 塑料反光、无结构布片 |
| 绸缎 | 低强度方向性高光 | 镜面亮片、现代礼服感 |
| 旧木 | 可见木纹与磨损边，不腐烂 | 发光神木、过度裂纹 |
| 皮革 | 哑光、边缘使用痕迹 | 黑亮乳胶质感 |
| 铜器 | 暖铜、轻氧化、边缘微亮 | 黄金珠宝化 |
| 青石 | 湿润时局部反光、苔痕克制 | 整面镜面或塑料石 |
| 水面 | 有流向、反射被风雨打散 | 纯透明玻璃、静止贴图 |

## 四、灯光与色彩基准

- 白天：暖白主光＋天青环境光，肤色中性，不泛黄。
- 室内：窗外冷光＋灯烛暖光，人物眼神光必须保留。
- 灯市：橙金灯笼作动机光，环境仍保留蓝紫夜色，禁止整屏橙红。
- 雨夜：青灰环境光＋局部火把暖光，湿面反射帮助读动作，禁止压黑五官。
- 回忆：不使用褐黄老照片滤镜；改用略暖高光、柔和反差和极轻边缘辉光区分时间。
- 长生金纹：色值以柔和旧金为主，亮度高于皮肤但不溢光吞掉纹理。

六篇章保留以下主色：柳渡桃粉／竹绿／暖白；风铃山路晴蓝／朱红／木色；烟水镇水绿／靛青／橙灯；千灯城绯紫／金橙／湖蓝；雨山驿雨青／药草绿／银灰；雨山关月白／藤绿／泉水青。

## 五、镜头和竖屏构图

### 基本规格

- 成片画幅9:16；关键脸、手和道具尽量放在画面中央80%安全区。
- 上方预留约8%标题安全区，下方预留约18%字幕安全区，不让关键信息压在底部。
- 关系戏以中近景、近景为主；每集只保留1—2个建立空间的大全景。
- 同一画面尽量不超过5张清晰人脸；群众用前后景遮挡和景深分层。

### 镜头用途

| 用途 | 等效焦段 | 画面原则 |
|---|---:|---|
| 地点建立 | 24—35mm | 竖向利用屋檐、灯串、桥索与水峡高度 |
| 双人关系 | 45—65mm | 肩部以上留手部动作，避免只拍大头 |
| 情绪特写 | 75—90mm | 景深适中，眼睛与关键发带同时清楚 |
| 道具证据 | 85—100mm | 封泥、铃舌、册页纹理可读，不凭空旋转 |
| 短打追逐 | 24—40mm | 先交代方向再运动，少用高速环绕 |

### 镜头运动

- 常用：缓推、缓拉、短摇、角色跟移、固定机位内调度。
- 喜剧：固定镜头留反应时间，利用前后景进出和停顿，不靠镜头疯狂抖动。
- 打斗：单镜头只承担一个动作信息；每2—4秒设置明确落点，避免长时间无规律绕拍。
- 情绪：以眼神、手指、递物和站位变化为主，禁止每句台词都切正反打大特写。

## 六、表演和动画基准

- 常态表情幅度克制，眉、眼、唇不同步到位，保留真实思考停顿。
- 喜剧允许一次性夸张，例如裴策被鹅追、阿九护食，但下一镜恢复模型比例，不发生五官重塑。
- 情感优先通过“先护人后反应、想说又收回、递物未松手、站位靠近”表达。
- 动作遵守重量：王铁山沉、柳三娘快准、秦归雪省力、阿九低位灵活、裴策整齐但易狼狈。
- 发尾、披风、袖口只做轻微二级运动；禁用持续无风自动飘动。
- 打斗不血腥，重点是缴械、挡、拉、封路、跌入染缸和狼狈反差。

## 七、资产一致性流程

1. 先生成角色正、侧、背与三分之二脸基准，锁定同一参考图、随机种或角色模型。
2. 再生六格表情和四格动作，确认脸、发、服装层级不变。
3. 场景先出无人物主视图、反打视图和鸟瞰动线图，再让角色入景。
4. 机关必须先出关闭、触发、结果三态，明确物理因果后才能进入动作分镜。
5. 特效单独生成透明层或干净背景版，强度以“看得见但不抢脸”为准。
6. 图生视频每次只写一个主体动作＋一个镜头动作，禁止在单条提示词内堆叠多段剧情。
7. 平台若支持角色参考、场景参考、深度图、姿态图或固定种子，必须使用；提示词不能替代参考资产。

## 八、单镜头提示词公式

`全局主提示词＋资产编号与固定外观＋地点编号与空间锚点＋唯一动作＋关系站位＋景别焦段＋动机光＋天气与材质反应＋图生视频追加词＋全局负面提示词`

示例：

> 高品质东方幻想3D动画漫剧，风格化半写实，C001A秦归雪在S001柳渡花市替C002阿九挡刀后半跪，青白短披风沾少量雨水，腹侧细金纹开始自愈，阿九惊慌抓住她袖口，桃花纸伞与竹绿棚布形成前后景，中近景，50mm等效焦段，暖白日光与棚下柔影，镜头缓慢推近，同一角色模型与服装材质，动作重心真实，金纹发光面积低于5%，无闪烁。

## 九、全局验收红线

- [ ] 任一截图都能判断为同一部东方古风3D动画漫剧。
- [ ] 不出现二维描边、真人换脸、塑料手办或游戏录屏质感。
- [ ] 秦的金纹、牵星线、霜白鬓发在所有镜头遵守同一规则。
- [ ] 场景明亮有季节和地域差，不回到统一灰黄风沙。
- [ ] 人物年龄、体型、职业和服装材质清晰可分。
- [ ] 喜剧不破坏模型一致性，打斗不牺牲空间方向。
- [ ] 机关看一遍能理解触发与结果，末法纹样只作稀少背景信息。
- [ ] 竖屏字幕区不压住脸、手、信、铃、册页等剧情关键资产。
