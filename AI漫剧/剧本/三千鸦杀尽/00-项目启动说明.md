# 《三千鸦杀尽》项目启动说明（低成本情感冒险版）

## 当前定位

- 形态：中文 AI 漫剧 / 竖屏连续短剧
- 第一季：24 集，每集 2—3 分钟；先制作 1—3 集验证效果
- 主类型：长生者情感追溯、荒野公路冒险
- 核心情感：长生者沿着故人留下的路，逐件收回一份迟到了近三百年的爱
- 受众：18—35 岁女性为主，兼顾冒险悬疑受众
- 内容比例：感情与人物约 60%，冒险与悬疑约 40%
- 叙事优先级：沈渡的爱意 > 秦的迟到理解 > 冒险求生 > 远古世界观暗线
- 当下核心人物：秦归雪、阿九、王铁山、裴策。裴策既在队伍之中，也是持续制造错误决策与争夺的核心反派。

## 本轮方向调整

| 调整项 | 新版本处理 |
|---|---|
| 秦与远古纪元关系过强 | 删除“活钥匙”“遗迹权限”“力量烧记忆”等设定，第一季不解释秦为何长生 |
| 容易变成末法修仙文 | 不出现修炼、境界、灵力、法术和飞升体系；危险均可被理解为异兽、毒瘴、旧机关与特殊地貌 |
| 世界观喧宾夺主 | 前三季总共只放三处背景异常，第一季仅留龟甲丘壁画一处 |
| 情感线不足 | 第一季从十段冒险缩为三段，把空间让给五人旧队相处、沈渡的偏爱与秦当年的误读 |
| 制作规模过大 | 不限制随队探路者与迁民人数，只固定秦、阿九、王铁山、裴策四名核心人物；其他人均为低台词小配角、单元角色或反派，用远景、车辙、烟火和声音暗示规模 |
| 场景资产过多 | 第一季只用荒漠、石林、洞窟三套主场景；今昔两线复用同一地点 |
| 怪物特效过多 | 第一季只有沙蜥一个完整生物资产，酸藤只做局部 |
| 十关过密 | 十段冒险完整保留，拆为 24+24+32 集三季，而非一季走完 |

## 远古暗线控制

- 第一季第 20 集：龟甲丘一幅升空壁画，仅作背景，不与秦建立直接关系。
- 第二季季终：秦在旧祭台听见一次陌生称谓，立即被现实危险打断。
- 第三季季终：废塔残纹与壁画相同，秦看一眼便继续走。

前三季除此之外不讨论远古文明、秦的权限、身世或历史使命。

## 第一季创作底线

- 沈渡已经去世，不复活、不转世、不用幻影陪伴秦。
- 阿九不是白九转世，也不承担秦身世谜题。
- 秦只是活得很久、经验很多、恢复力略强；她不能施法，不能单人碾压大型怪物。
- 沈渡的爱只通过行动证明，不靠长篇表白；旧队其他人可以看懂和调侃，但不能替他表白。
- 每个冒险单元只在 3 个关键节点触发完整闪回；普通集坚持留在当下，用旧物、字迹和人物反应推进。
- 每处遗物都必须先帮助秦或队伍活下来，再承担情感意义。
- 冒险解法以常识、观察、协作为主，避免靠神秘力量临时解题。
- 每集画面尽量控制在 1 个主场景、1—3 个同框角色、1 个明确动作目标。
- 大队伍可以在剧情上存在，但不建立固定人数账本；除核心四人外，任何随队角色必须承担伤员、证人、阻力或反派中的至少一种功能。
