# 《三千鸦杀尽》第一季《铃响之前》·质量自检

## 结论

第一季已由“60 集走完十关”调整为“24 集走三关”。新增双时空同行线后，沈渡不再只是留信人，而成为实际参与每次破关和情感推进的第二主角。

现在的观看重心是：观众先看懂沈渡的爱，秦再迟一步看懂。冒险负责触发记忆、制造选择和推进路程，不再抢占全部篇幅。

当下线已统一为秦、阿九、王铁山、裴策四名核心人物。探路者与迁民人数不设限，除核心四人外均按小配角、单元角色或反派使用，不建立人数连续性负担。

## 最重要的写作风险

| 风险 | 控制方式 |
|---|---|
| 沈渡过度完美 | 保留他吃醋、嘴硬、判断失误和情绪失控，但不损害尊重秦的底色 |
| 旧队只负责起哄 | 让许长庚负责现实判断、白九负责拆穿、阿梨负责情感观察，各自仍有冒险职责 |
| 秦显得冷血 | 她不是不在乎，而是不理解短暂关系为何需要命名；用她照顾人和保存物件证明感情能力 |
| 过去场切碎当下危机 | 全季只用9次；亲历残忆由感官触发，客观过去由物件硬切，回到当下后立即接续动作或危机 |
| 每集都像“沈渡又为她做一件事” | 交替写保护、生活细节、争执、尊重、放手和晚年选择 |
| 感情线变成直白甜宠 | 不用长篇告白和持续肢体暧昧，靠行动、停顿、错过与旧队反应表达 |
| 季终缺乏完成感 | 第 24 集回答“他为什么回来”，同时保留秦尚未完成的回应 |

## 完整剧本门禁

每集写作前检查：

1. 当下危机是什么，是否能在一个主场景内成立？
2. 本集是否属于既定9个过去场节点？如果不是，禁止进入过去画面。
3. 如果是过去场，本集使用“秦的亲历残忆”还是“客观过去场”，并给出哪一半破关方法或核心情感答案？
4. 当下队友补上了哪一半？
5. 本集新增了沈渡哪一种爱意，而不是重复“保护她”？
6. 秦当年为何会误读这个动作？
7. 旧队旁观者的反应是否符合各自性格？
8. 是否误加了秦身世、修炼体系或宏大远古任务？
9. 结尾钩子是下一步危险，还是下一层感情认知？
