# 《三千鸦杀尽》第一季·世界与冒险规则

## 一、观众需要知道的世界

多年旱灾后，朝廷组织百姓向西迁徙。秦所在的探路队提前主迁民队三日出发，任务是找水、探路、标出不能走的禁地。随队人数不设固定值，故事只持续跟随秦归雪、阿九、王铁山、裴策四名核心人物。

西境荒凉，散落着古战场、坍塌城寨、地下甬道和无人维护的旧机关。野兽在封闭环境中长得异常，谷地会积毒，石林里有腐蚀性藤蔓。民间把无法解释的地方称作“旧地”，仅此而已。

第一季不解释旧地来自什么文明，也不建立修炼体系。冒险规则必须能用观察、经验和协作理解。

## 二、秦归雪的长生规则

- 她不会自然衰老，外貌始终停在二十余岁。
- 她会受伤、会流血、会疼，也可能被困死、烧死或窒息。
- 她的伤恢复得比常人快，但以“数日或数月”为单位，不是当场复原。
- 她没有法术、灵力、境界和储物能力。
- 她战斗靠的是活得久、见得多、反应稳，以及熟悉沈渡留下的判断方式。
- 她的记忆会像普通人一样被岁月磨损。遗忘不是使用能力的代价，而是长生本身的孤独。

第一季不回答她为何长生。

## 三、旧地危险规则

| 危险 | 可见原因 | 解法原则 | 禁止写法 |
|---|---|---|---|
| 黑风 | 地缝喷出灼热毒尘 | 看风向、找低处和背风洞 | 秦施法挡风 |
| 酸藤 | 对热与震动敏感的植物 | 夜间休眠、减少接触 | 法宝一剑清场 |
| 旧机关 | 木石铜铁构成的年久装置 | 回声、配重、楔子、顺序 | 神秘权限自动开门 |
| 毒瘴 | 谷底腐物、矿气与湿雾 | 限时、遮口鼻、用火辨流向 | 瘴气拟人成精 |
| 异兽 | 长期封闭环境中的异常野兽 | 找习性、用地形、团队围困 | 巨兽无限变大 |
| 霜苔鸣响 | 苔层受踩踏后共振 | 踩旧脚印、控制节奏、不能久停 | 精神法术控制全员 |

## 四、系列路线与第一季终点

```text
北境集镇
  → 黑风渊
  → 石林海 / 桂市镇
  → 龟甲丘地下旧道
  → 疫谷 / 废村
  → 老鼍脊甬道
  → 石窟群
  → 霜苔原
  → 废城古井
  → 沙匪谷
  → 敦煌废塔 / 归雪木
```

沈渡近三百年前从敦煌向东走到长安。晚年他又独自反走一次，把危险处重新确认并留下信物。前三季的秦从东向西，分段倒着收回这些东西；抵达敦煌之后，后续季度才会向长安走正向旧路。

季度重新拆分后：

- 第一季止于龟甲丘，只走黑风渊、石林海、龟甲丘。
- 第二季继续疫谷、老鼍脊、石窟群。
- 第三季完成霜苔原、废城、沙匪谷、敦煌废塔。
- 秦抵达敦煌后，第四季才可能开启向长安的正向旅程。

## 五、沈渡路标系统

路标不是远古密码，而是沈渡和旧队伍共同使用的探路记号。

| 标记 | 含义 |
|---|---|
| 一横两点 | 可停留，附近有水 |
| 断环 | 前方结构损坏，不可强行通过 |
| 右缺三角 | 右路危险较小，需贴墙走 |
| 圆中“秦”字 | 专门留给秦，附近有信或旧物 |
| 反写“渡”字 | 图是给追踪者看的假路，真正路线在背面或下方 |

这些符号最大的情感意义是：沈渡知道秦会忘，所以不用只有两人能懂的暗语，而把每一步都写得简单、具体、能救命。

## 六、前三季三处远景暗线

以下内容只出现，不解释：

1. 第一季第 20 集，龟甲丘壁画：褪色人影立于高台，头顶有向上延伸的亮线。只作背景，不与秦直接关联。
2. 第二季季终，石窟旧祭台：秦触碰石面时听见陌生声音喊她一个听不清的称谓。她立刻被落石打断，不再追问。
3. 第三季季终，敦煌废塔：塔基有与壁画相同的残缺纹样。秦看见后只停一瞬，继续向东。

三处暗线不在同一季形成线索链，不制造“秦是钥匙”或“秦肩负使命”的印象。

## 七、当世人际冲突

### 探路队与主迁民队

主迁民队在后方三日路程之外，探路队人数不作固定限制。第一季当下核心人物固定为秦、阿九、王铁山、裴策，其中裴策是队内核心反派。其他随队者只在需要伤员、证人、劳力或阻力时出现，视觉上使用少量通用模型、背影和画外音。

柳三娘是龟甲丘附近受雇修旧道的机关匠，第 21 集短暂协助判断木楔，第二季才正式加入。静玄与老袁留到后续季度。

### 裴策的动机

裴策是随队监官，负责把安全路线交回朝廷。他从沈渡信中误判敦煌旧塔藏有金银或水源密图，因此争夺信件和地图。他不知道秦的起源，也不追查她的长生秘密。

他带来的冲突是贪功、夺图、抢先和错误决策，都是低成本的人物冲突，不需要额外世界观特效。

## 八、时间线

| 时间 | 事件 |
|---|---|
| 很久以前 | 秦已经开始在人世间行走，具体起点不明 |
| 距今约 300 年 | 秦在敦煌结识沈渡、许长庚、白九、阿梨，五人同行至长安 |
| 距今约 294 年 | 秦因一次意外离开队伍，之后再未见到四人 |
| 距今约 292—280 年 | 沈渡用十二年反走旧路，修路标、托信物、记下所有险处 |
| 距今约 280 年 | 沈渡去世，其余旧友先后留下各自的物件 |
| 第一季第 1 集 | 秦随先遣队西行，重新踏上当年的反向旧路 |

沿途所有人口径统一为“近三百年”，不再混用“两百年”和“几百年”。

## 九、信息揭露边界

### 第一季必须回答

- 沈渡是否爱秦：观众明确知道；秦只承认他对自己不同。
- 沈渡为什么留第一批信物：怕秦将来独自路过时受伤。
- 沈渡是否还活着：已经去世，不做假复活。
- 沈渡为何能预判前三关危险：他晚年回来复核并修过这段路。
- 秦为何继续西行：先是随队，收到信后主动寻找其余托付。
- 裴策为何抢信：他误以为路线通往宝藏或秘密水源。

### 第一季不回答

- 秦为何长生。
- 久远年代发生过什么。
- 壁画、旧祭台和塔基纹样为什么彼此相似。
- 秦听见的陌生称谓是什么。
- 沈渡晚年是否把整条路都走完，以及最后一封信写了什么。

## 十、爱意表达规则

- 沈渡不写长篇情书，每封信先写“怎么活”，最后才有一句私人话。
- 爱意必须具体：水在哪里、哪家面好吃、桂花糕少放糖、旧门先敲几下。
- 感情由关键同行闪回、信件、刻字、旧物和当下行为共同承担；完整闪回保持稀缺。
- 旧队三人都知道沈渡的感情，可以调侃、劝说和旁观，但不替他向秦表白。
- 秦很少哭。她的反应是把信折好、把破路标重新立稳、把食物照他说的做一遍。
- 每个冒险单元只安排 2—3 次关键回忆，围绕一个动作展开；其余集不进入过去画面。
- 最后的情感结论不是“永远等你”，而是“我知道你活得久，所以不让你替我停下”。

## 十一、低成本视觉母题

| 母题 | 表达 | 成本控制 |
|---|---|---|
| 青衣 | 秦在灰黄荒野中的固定识别色 | 全季不频繁换装，只做破损层级 |
| 铜铃 | 声音引路，也是沈渡的存在感 | 用音效和特写替代回忆大场面 |
| 信纸 | 字迹从工整到颤抖 | 静物镜头成本低、情绪效率高 |
| 火光 | 当下营地与过去回忆的连接 | 过去线复用同一营地资产 |
| 乌鸦 | 普通荒野乌鸦，不设定为超自然生物 | 用远处剪影或单只模型，不做群鸟特效 |
| 热水 | 第7—8集第一封信的情绪兑现 | 单一桌面、热气和手部镜头即可完成 |
