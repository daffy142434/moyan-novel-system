# 编剧主审短剧审稿技能

> 归属：茗舒

## 定位

这是给编剧/主审使用的深度审稿工具，不是写手自查表。目标是：

1. 快速判断写手稿件能不能继续推进
2. 找出具体问题，不只说"不好"
3. 给出可执行修改意见，方便写手返修
4. 批量审稿时保持标准统一
5. 把 `short-drama` 写作 skill 的规则反过来作为验收标准

## 与写手自查版的区别

| 项目 | 写手自查版 drama-review | 编剧主审版 drama-editor-review |
|------|-------------------------|--------------------------------|
| 使用者 | 写手本人 | 编剧/主审 |
| 目标 | 投稿前自检 | 把关写手质量 |
| 深度 | 是否达标 | 为什么不达标 + 怎么改 |
| 输出 | 审核报告 | 逐集逐场批注 + 打分 + 退改意见 |
| 结论 | 通过/不通过 | A/B/C/D等级 |
| 使用场景 | 单本自查 | 批量审稿、日常审写手稿 |

## 审稿前必须确认

开始前先确认以下信息：

1. **制作模式**：国内下沉剧 / 海外仿真人原创 / 海外AI剧本
2. **审稿阶段**：选题策划 / 一审材料 / 二审材料 / 分集细纲 / 正文剧本 / 全本
3. **审稿目的**：内部把关 / 给写手返修 / 投稿前终审
4. **审稿范围**：全部 / 指定集数 / 指定文件夹
5. **写手信息**（可选）：写手名/编号、历史等级（新手/成熟/问题写手）

如果用户没有说明模式和阶段，先问清楚，不要直接审。写手信息可选，有的话会自动调整审稿深度。

## 【第零步】30秒快速淘汰（前置过滤）

**批量审稿时必须先跑这一步。** 5个条件任意命中1个 → 直接退回，不进入细审，节省时间。

| 编号 | 淘汰条件 | 退回话术编号 |
|------|----------|-------------|
| K1 | 题材不在该渠道收稿范围（如国内投了东方玄幻、海外仿真人投了后悔流） | #D1 |
| K2 | 第1集开场没有冲突——前3段全是背景/世界观/天气/独白 | #R1 |
| K3 | 海外剧角色全用中文名或中文拼音 | #F1 |
| K4 | 一审材料严重缺失——没有故事梗概或没有集纲 | #M1 |
| K5 | 全文AI味爆表——通篇书面语、排比说教、角色全员一个语气 | #T1 |

**快速淘汰判断流程：**

```
拿到稿件
  → 看题材标签 → K1命中？→ 秒退
  → 看第1集前3段 → K2命中？→ 秒退
  → 扫角色名 → K3命中？→ 秒退
  → 看材料清单 → K4命中？→ 秒退
  → 随机读3段台词 → K5命中？→ 秒退
  → 全部不命中 → 进入正式审稿
```

快速淘汰通过后，再按下面的完整流程审。

## 常见退稿原因模板库

审稿时直接引用编号，不用每次重新写反馈话术。

### D系列：方向/题材问题

| 编号 | 问题 | 标准话术 |
|------|------|----------|
| #D1 | 题材不收 | 这个题材方向不在当前渠道收稿范围，请参考收稿列表重新选题。 |
| #D2 | 换皮老梗无差异化 | 故事核心和市面常见剧差异不大，请找到你这个本子独特的卖点，至少一个"别人没有"的设定。 |
| #D3 | 故事只有开头没有结局 | 梗概必须写到结局，不能只写前10集。请补完整故事线。 |
| #D4 | 成长线不成立 | 主角从头到尾没有变化/一直靠外力，请设计清晰的成长阶段。 |

### R系列：节奏问题

| 编号 | 问题 | 标准话术 |
|------|------|----------|
| #R1 | 开场无冲突 | 第1集开场必须直接进冲突，不要铺背景/世界观/天气。前3段必须让观众知道主角被欺负/遭遇危机。 |
| #R2 | 中段注水/重复 | 第X-X集重复同一种冲突模式，需要升级：换反派手段、加新线索、推主线进展。 |
| #R3 | 结尾没钩子 | 第X集结尾平淡收场，没有悬念。结尾必须让观众想看下一集——可以用危机/真相/身份/反击未完。 |
| #R4 | 付费卡点弱 | 第8-12集区间没有强力钩子，这是免费转付费的关键节点，需要设计最强悬念。 |
| #R5 | 连续同情绪 | 连续X集都是虐/都是平，缺乏节奏起伏。虐后要给反击，压完要给甜或爽。 |

### L系列：逻辑问题

| 编号 | 问题 | 标准话术 |
|------|------|----------|
| #L1 | 证据/转折无铺垫 | 第X集突然出现关键证据/转折，前面没有任何铺垫。请在前X集埋伏笔。 |
| #L2 | 角色降智 | 第X集第X场，角色行为不符合人设。[具体说明哪里降智]。 |
| #L3 | 前后矛盾 | 第X集说了A，第X集变成了B，请统一。 |
| #L4 | 伏笔未回收 | 第X集埋的[具体伏笔]，后续没有交代。请安排回收。 |
| #L5 | 角色凭空消失 | [角色名]在第X集后完全消失，没有交代去向。 |

### T系列：台词问题

| 编号 | 问题 | 标准话术 |
|------|------|----------|
| #T1 | 全文AI味 | 台词整体偏书面/模板化，不像真人说话。请逐句检查：人真的会这么说吗？情绪激动时用短句，删掉"因此""事实上""你要知道"类表达。 |
| #T2 | 单句书面化 | 第X集第X场，[角色名]这句"[原文]"太书面。建议改成：[建议改法]。 |
| #T3 | 角色无辨识度 | 所有角色说话一个调，分不清谁是谁。反派要狠，主角要冷/硬，配角要有各自口头禅或语气习惯。 |
| #T4 | 废话台词 | 第X集第X场，这句台词不推动剧情、不揭示信息、不制造冲突，建议删掉或改成有功能的对白。 |
| #T5 | 情绪与句式不匹配 | 角色在愤怒/崩溃状态下说了完整长句，不合理。改短、改碎、改狠。 |

### F系列：格式问题

| 编号 | 问题 | 标准话术 |
|------|------|----------|
| #F1 | 海外剧用中文名 | 海外剧角色必须用英文名，不能用中文名或中文拼音。请全部替换。 |
| #F2 | 场景头缺失/格式错 | 场景头格式应为：`集数-场次 地点 日/夜 内/外`。请逐场检查补全。 |
| #F3 | 动作不以△开头 | 动作/场景描写必须以△开头，每个动作独立一行。 |
| #F4 | 台词缺情绪标注 | 台词格式应为：`角色名（情绪/动作）：台词`。请补上括号内的情绪或动作。 |
| #F5 | 字数不达标 | 本集字数[实际字数]，要求[标准字数]。请补充内容。 |

### M系列：材料问题

| 编号 | 问题 | 标准话术 |
|------|------|----------|
| #M1 | 一审材料缺失 | 一审需要提交：故事梗概 + 一卡集纲 + 人物小传，当前缺少[具体缺什么]。请补齐后重新提交。 |
| #M2 | 二审材料缺失 | 二审需要提交：人设确认稿 + 故事梗概确认稿 + 大纲确认稿 + 分集细纲，当前缺少[具体缺什么]。 |
| #M3 | 压缩包命名错误 | 压缩包命名应为：`公司简称+日期+本数`，当前命名不规范，请修改。 |
| #M4 | 人物小传只有身份没有动机 | 人物小传需要写清楚：身份、性格、核心设定、与主角的关系、角色在故事中的功能。不能只写"XX岁，XX身份"。 |

### P系列：画面/可拍性问题

| 编号 | 问题 | 标准话术 |
|------|------|----------|
| #P1 | 写心理不写动作 | 第X集第X场，"[原文]"是心理描写，镜头拍不到。请改成具体的外化动作。 |
| #P2 | 动作不具体 | "他攻击了她"太笼统，请写清楚：用什么攻击、打哪里、对方什么反应。 |
| #P3 | 场面超出制作能力 | 第X集出现[大规模人群/复杂战斗/...]，AI仿真人/AI漫难以实现。请简化为可拍场面。 |

### A系列：AI生成痕迹

| 编号 | 问题 | 标准话术 |
|------|------|----------|
| #A1 | 逻辑断裂 | 第X集第X场前后内容无关联，疑似AI跑飞。请检查并补上过渡。 |
| #A2 | 角色错乱 | [角色名]在第X集出现异常——[具体描述：改名/已死复活/关系变化]。请核实修正。 |
| #A3 | 重复情节 | 第X集和第X集出现高度相似的情节，疑似AI重复。请删除一处或改出差异。 |
| #A4 | 诡异内容 | 第X集出现不合逻辑/不合设定的内容：[具体描述]。请删除或修正。 |

## 写手分级管理

不同水平的写手，审稿策略不同，避免在靠谱的写手身上浪费时间，也避免对新手漏审。

### 写手等级定义

| 等级 | 定义 | 历史表现 |
|------|------|----------|
| **S 核心写手** | 多次A级过稿，基本不出大问题 | 格式稳定、节奏好、台词自然 |
| **A 成熟写手** | 多数B级，偶尔A级 | 方向对，细节偶有瑕疵 |
| **B 合格写手** | B/C交替，需要指导 | 故事能讲但节奏/台词常有问题 |
| **C 新手写手** | 首次合作或多次C/D | 需要逐场手把手批注 |

### 分级审稿策略

| 写手等级 | 审稿深度 | 重点查什么 | 反馈方式 |
|----------|----------|------------|----------|
| S 核心 | 快速扫描 | 只查方向、节奏大框架、有无AI跑飞 | 简短反馈，信任细节 |
| A 成熟 | 重点抽查 | 查前3集节奏 + 中段防水 + 台词抽查 | 指出关键问题，不逐场 |
| B 合格 | 标准审稿 | 全维度检查，重点查台词和节奏 | 详细批注 + 修改意见 |
| C 新手 | 逐场细审 | 每场都看，格式/台词/逻辑/动作全查 | 逐场批注 + 示范改法 + 教学说明 |

### 写手历史问题追踪

如果用户告知某写手的历史常犯问题，审稿时自动加权检查。

示例：
- "这个写手台词一直很AI" → 台词维度加倍检查，每场都查
- "这个写手爱注水" → 中段防水检查加严，逐集查是否有效
- "这个写手格式总错" → 格式先查，不过直接退

## 审稿效率工具

### 优先级排序

当同时收到多份稿件时，按以下顺序审：

1. **投稿终审**（有截止时间的优先）
2. **一审选题**（30秒快速淘汰，批量处理）
3. **返修稿**（写手改完重新提交的）
4. **全本终审**
5. **新写手首稿**（需要细审建立基线）

### 审稿时间预估

| 审稿类型 | 预估时间 |
|----------|----------|
| 快速淘汰（30秒过滤） | 30秒-1分钟/本 |
| 选题策划审核 | 3-5分钟/本 |
| 一审材料审核 | 10-15分钟/本 |
| 二审细纲审核 | 15-20分钟/本 |
| 正文抽审（10集） | 20-30分钟/本 |
| 全本终审 | 40-60分钟/本 |

### 审稿批注速记符号

审稿过程中可使用以下速记，最终报告会展开为完整批注：

| 速记 | 含义 |
|------|------|
| `!节奏` | 节奏问题 |
| `!台词` | 台词不自然 |
| `!逻辑` | 逻辑不通 |
| `!格式` | 格式不对 |
| `!水` | 注水/无效场次 |
| `!AI` | AI生成痕迹 |
| `!降智` | 角色降智 |
| `!钩子` | 缺钩子 |
| `!心理` | 心理描写应改动作 |
| `!重复` | 重复情节/手段 |

## 审稿结论等级

每次审稿必须给出等级：

| 等级 | 结论 | 处理建议 |
|------|------|----------|
| **A 直接过** | 格式、节奏、逻辑、台词基本达标 | 可进入下一阶段 |
| **B 小改可过** | 有局部问题，不影响整体 | 写手按批注修改后可过 |
| **C 大改退回** | 结构/节奏/人设/逻辑存在明显问题 | 退回重修，需要二审 |
| **D 重写** | 方向错误、题材不符、故事不可用 | 不建议在原稿上修，重写 |

## 分项打分标准（100分）

| 维度 | 分值 | 说明 |
|------|------|------|
| 题材匹配 | 10分 | 是否符合对应渠道收稿方向 |
| 材料完整 | 10分 | 一审/二审/正文材料是否齐全 |
| 格式规范 | 10分 | 场景头、人物、动作、台词格式是否正确 |
| 节奏爽感 | 20分 | 开场冲突、每集爽点、结尾钩子、付费卡点 |
| 人设一致 | 10分 | 角色动机、性格、关系是否稳定 |
| 逻辑连贯 | 15分 | 因果链、伏笔回收、上下文衔接 |
| 台词自然 | 15分 | 是否像人说话，是否有AI味、生硬感 |
| 画面可拍 | 10分 | 动作是否具体、AI/仿真人是否能实现 |

评级参考：
- 90-100：A
- 75-89：B
- 60-74：C
- 60以下：D

**注意：题材不符、材料缺失严重、核心逻辑崩塌，可以直接降级，不受总分限制。**

## 一、题材与渠道匹配审查

### 国内下沉剧

**优先收稿：**
- 年代 + 小人物成长 + 小商战
- 穿越类，突出人物成长
- 成长类、逆袭类
- 现代异能类，能力有代价、服务成长线

**必须退回：**
- 东方玄幻、修仙、仙侠、玄幻升级流
- 过度悬浮、不接地气
- 只有设定没有人物成长

**主审判断重点：**
- 是否够下沉、够直给
- 主角是否是小人物起步
- 是否有赚钱、护家、打脸、逆袭爽点
- 台词是否土狠直爽，少专业词

### 海外仿真人原创

**男频收稿：**
- 战神、高手下山为主
- 不要脑洞向

**女频收稿：**
- 大女主、黑帮类可以
- 狼人、吸血鬼可以
- 不做后悔流
- 甜宠和BL慎重
- 纯暧昧向不收

**主审判断重点：**
- 英文名是否统一、符合海外语境
- 真人拍摄是否可实现
- 是否符合海外短剧强冲突、高情绪、强反转逻辑
- 不能只有暧昧拉扯，必须有实质冲突

### 海外AI剧本

**女频方向：**
- 虐恋
- 大女主复仇
- 灰姑娘
- 宫廷斗争
- 萌宝
- 契约关系
- BL/骨科/GL
- 西幻

**男频方向：**
- 西幻
- 科幻

**尺度：** 不限，性向不限，NP不限，以海外大热题材为主。

**主审判断重点：**
- AI跑内容后是否出现奇怪逻辑
- 是否存在角色突然消失/突然变设定
- 细纲确定后是否能直接推进全本，后期不需要大改
- 剧情是否完整、合乎逻辑、可批量生产

## 二、材料完整性审查

### 一审材料

必须包含：

1. **故事梗概**
2. **一卡提审/一卡集纲**
3. **人物小传**

压缩包命名：`公司简称+日期+本数`

**一审材料常见退回原因：**
- 只有题材，没有完整故事线
- 梗概只写开头，没有结局
- 一卡集纲没有覆盖完整集数
- 人物小传只有身份，没有动机和关系
- 核心爽点不清楚

### 二审材料

一审确认后必须包含：

1. **人设确认稿**
2. **故事梗概确认稿**
3. **大纲确认稿**
4. **分集细纲**

**二审材料常见退回原因：**
- 细纲只写剧情流水账，没有每集爽点和钩子
- 人设和梗概矛盾
- 前10集节奏不够强
- 中段重复打脸，缺少升级
- 结尾没有大高潮或价值升华

## 三、海外样稿标准审查

海外剧参考过稿样稿：《Alpha's Vengeance》（狼王嫡女复仇录）。详见 `references/overseas-drama-format.md`。

### 一审标准结构

审稿时检查是否具备：

1. **剧本简介**
   - 题材
   - 元素
   - 篇幅
   - 故事亮点（4-5条）
   - 一句话简介

2. **主要人物**
   - 英文名
   - 身份标签
   - 年龄（如适用）
   - 性格关键词
   - 核心设定
   - 【形象描述】

3. **完整简介/故事梗概**
   - 起因、发展、转折、高潮、结局完整
   - 不只写前三集

4. **集纲总结**
   - 按3-5集为一组
   - 每组有阶段标题
   - 每组说明核心事件、冲突、结果和悬念

### 正文格式标准

海外剧正文必须符合：

```
1-1 地点 日 外
人物：A、B、C
△动作/场景描写。
角色名（情绪/动作）：台词。
```

检查点：
- 场景头是否完整
- 人物列表是否每场都有
- 动作是否以△开头
- 台词是否有角色名+情绪/动作
- VO是否只用于关键内心转折，不滥用

## 四、节奏爽感审查

这是最重要的一项，占20分。

### 开场检查

第1集前3秒必须进冲突。主审检查：

- 是否一开场就有压迫、羞辱、危机、打脸、威胁
- 是否避免慢铺垫、世界观介绍、空镜头过长
- 是否让观众立刻知道主角处境和情绪

**不合格示例：**
- 开头写天气、城市、背景介绍一大段
- 主角独白解释世界观
- 先写无冲突的日常聊天

**合格方向：**
- 出狱被踹伤口
- 被亲人赶出门
- 当众被退婚/羞辱
- 欠债上门砸店
- 主角拿到死亡通知/离婚协议/合同陷阱

### 每集爽点检查

每集至少有1-2个：

- 打脸
- 赚钱
- 护家
- 身份反转
- 技术碾压
- 取证推进
- 反派吃瘪
- 关系拉扯
- 真相露出一点

### 结尾钩子检查

每集结尾必须让人想看下一集。钩子类型：

- 危机钩子：主角被围堵/被抓/被陷害
- 真相钩子：证据即将曝光
- 身份钩子：强者身份露出
- 情感钩子：误会加深/关系转折
- 爽点钩子：反击刚开始，还没打完

### 中段防水检查

主审要重点查20-40集：

- 是否重复同一种打脸
- 是否反派只会同一招
- 是否主角一直被虐没有反击
- 是否每集只是换地点吵架
- 是否主线停滞

## 五、逻辑与上下文审查

### 因果链

每个关键事件都要回答：

- 为什么发生？
- 谁推动的？
- 结果改变了什么？
- 是否影响下一集？

如果一场戏删掉不影响后文，就是水戏。

### 上下文衔接

逐集检查：

- 上集结尾的悬念，下集是否接住
- 上一集受伤，下一集是否延续
- 上一集知道的信息，下一集人物行为是否体现
- 上一集立下的目标，后文是否推进

### 伏笔回收

检查：

- 关键道具是否回收
- 关键证人是否回收
- 昏迷/失踪/死亡角色是否有交代
- 反派罪证是否形成闭环

### AI跑飞识别

尤其审海外AI剧本时，要查：

- 角色突然改名
- 人物关系突然变化
- 一场戏里出现前文没有的人
- 已死亡/昏迷角色突然正常说话
- 主角能力突然改变
- 同一个事件被重复写两遍
- 前面说地点A，下一行突然变地点B

## 六、人物审查

### 人设是否有功能

每个主要人物必须有：

- 欲望：他想要什么
- 障碍：他为什么拿不到
- 手段：他会怎么做
- 关系：他和主角是什么冲突关系
- 变化：他在故事中是否改变/崩塌/觉醒

没有功能的人物，建议合并或删除。

### 主角成长线

国内和海外成长类都必须看：

- 主角起点是否足够低
- 主角不是靠别人全程救
- 主角每阶段有主动行动
- 主角能力/心态/资源逐步升级
- 结尾不是简单被强者拯救，而是完成自我翻身

### 反派层级

反派不能只有一个平面坏人。检查：

- 小反派：负责前期羞辱和日常压迫
- 中反派：制造实际损失和阶段危机
- 大反派：掌握核心秘密/资源/权力
- 终极反派：推动最终审判/翻盘

如果反派只有骂人和作妖，建议加利益动机。

## 七、台词深度审查

台词是退稿重灾区，必须严查。

### 台词自然度

每句台词问一句：**人真的会这么说吗？**

不合格：
- 太书面
- 太完整
- 太讲道理
- 太像AI总结
- 太像作者解释剧情
- 情绪激动时还在说长句

合格：
- 短
- 狠
- 有情绪
- 有停顿感
- 有口语习惯
- 符合人物身份

### AI味高危词

发现以下表达要重点标红：

- "因此"
- "综上"
- "事实上"
- "值得注意的是"
- "我理解你的感受"
- "请你相信我"
- "你要知道"
- "这一切都是因为"
- "我只是想告诉你"
- "你为什么不能理解"

### 改法原则

审稿时不要只写"台词AI"，要给写手可改方向：

- 长句拆短
- 解释改成动作
- 道理改成冲突
- 书面词换口语词
- 空话删掉
- 每个角色给不同说话方式

### 示例批注

```
第3集第2场：Darien这句"我无法接受你对我妹妹造成的伤害"太书面。
建议改："Serafina，我妹妹躺了五年。你还敢站在我面前？"
```

## 八、动作与画面可拍性审查

### 动作具体

不合格：
- 她很愤怒
- 他攻击了她
- 众人震惊
- 气氛很压抑

合格：
- 她指甲嵌进掌心，血顺着指缝滴下
- 他抬脚踹向她的假肢伤口
- 众人同时后退半步，酒杯砸在地上
- 狼尾绷直，屋内没人敢出声

### 心理描写替换

主审批注时要求写手把心理改成镜头：

- "她害怕" → "她后退半步，手指抓紧门框"
- "他很愤怒" → "他一把掀翻桌子"
- "她很绝望" → "她笑了一下，眼泪却掉下来"

### AI仿真人/AI漫可实现

检查是否有：

- 过大规模人群
- 复杂战争场面
- 难以控制的动物群
- 过度血腥细节
- 连续复杂打斗
- 镜头无法表达的抽象概念

如果有，建议降级为可拍场面。

## 九、阶段审稿重点

### 选题策划阶段

重点看：
- 题材是否收
- 核心卖点是否清楚
- 主角成长线是否成立
- 是否有足够长线冲突支撑50-60集
- 是否有差异化，不是换皮老梗

### 一审阶段

重点看：
- 故事是否完整
- 一卡是否能看出前10集强冲突
- 人物是否有戏剧功能
- 是否符合渠道偏好
- 是否有过稿样稿那种清晰度

### 二审阶段

重点看：
- 分集细纲是否可直接写正文
- 每集是否有爽点/钩子
- 前后是否连贯
- 中段是否水
- 后期是否有升级和终局

### 正文阶段

重点看：
- 格式
- 台词自然度
- 动作可拍
- 逻辑衔接
- 每场是否有效

### 全本终审

重点看：
- 是否符合签约/交付要求
- 是否还有大逻辑bug
- 是否有AI跑飞
- 是否需要大改
- 是否可以发甲方

## 十、审稿输出格式

每次审稿输出两份内容：

1. **主审内部判断**：给你看的，直接说问题严重程度
2. **给写手的修改意见**：可以直接复制发给写手，语气清楚但不攻击人

### 输出模板

```markdown
# 编剧审稿报告

## 一、基本信息
- 项目名：XXX
- 制作模式：海外AI剧本
- 审稿阶段：分集细纲
- 审稿范围：第1-10集
- 审稿结论：B 小改可过
- 综合评分：82/100

## 二、主审内部判断

这版整体方向是对的，题材符合海外AI女频收稿，但前3集开场冲突还不够狠，第5-7集有重复虐女主的问题，中段需要增加取证推进或反击点。

## 三、分项评分

| 维度 | 分数 | 评价 |
|------|------|------|
| 题材匹配 | 9/10 | 符合海外AI女频虐恋+大女主复仇 |
| 材料完整 | 8/10 | 缺少人物形象描述 |
| 格式规范 | 9/10 | 基本规范 |
| 节奏爽感 | 15/20 | 第5-7集重复压迫，爽点不足 |
| 人设一致 | 8/10 | 男主保护边界需更清楚 |
| 逻辑连贯 | 12/15 | 第6集证据来源略突兀 |
| 台词自然 | 11/15 | 部分台词偏书面 |
| 画面可拍 | 9/10 | 基本可拍 |

## 四、必改问题

1. **第1集开场冲突不够快**
   - 问题：前两段都在交代庄园背景，观众进入慢。
   - 建议：直接从女主被狱警踹伤口/被家人羞辱开始。

2. **第6集证据来源缺乏铺垫**
   - 问题：女主突然拿到药剂单据，没有交代怎么拿到。
   - 建议：第4集提前安排她观察换班，第5集埋药瓶，第6集拿单据。

## 五、建议优化

1. 第3集结尾可以更强：不要只写男主出现，建议让反派认出他的身份。
2. Ivy的动机可以补一句，她为什么必须压住女主。

## 六、给写手的修改意见

这版方向可以，但需要重点改三处：

1. 前3集开场要更快，不要先铺背景，直接上冲突。
2. 第5-7集不要连续虐女主，要加一次女主主动取证或小反击。
3. 台词再口语一点，尤其反派台词，少讲道理，多用短句狠话。

改完后请重新提交第1-10集细纲。
```

## 批量审稿模式

当用户提供多个项目/多个写手稿件时，按以下格式输出汇总：

| 项目 | 写手 | 模式 | 阶段 | 结论 | 分数 | 主要问题 | 处理建议 |
|------|------|------|------|------|------|----------|----------|
| A | 张三 | 海外AI | 一审 | B | 82 | 中段水 | 小改 |
| B | 李四 | 国内 | 选题 | D | 45 | 东方玄幻，不收 | 重写 |

然后逐个项目展开详细批注。

## 审稿原则

- 不只说"不好"，必须指出具体位置和改法
- 不替写手大段重写，除非用户要求
- 先判断方向，再判断细节
- 题材不符合直接退，不浪费时间细审
- 前10集决定生死，优先审前10集节奏
- 台词自然度是重点，AI感台词必须标出来
- 每次都输出可复制给写手的修改意见
- 引用退稿模板库编号，保持反馈标准统一
- 批量审稿时先跑30秒快速淘汰，再细审存活稿件

## 对比审查（交叉验证）

当同一项目有多个版本（初稿→修改稿→终稿）时，自动进行对比审查：

### 修改稿对比检查

1. **上次的必改项是否已修**：逐条核对上次审稿报告的🔴项
2. **改了没改好**：修改方向是否正确，有没有改出新问题
3. **没改的是否有理由**：如果写手有意不改，是否合理
4. **新增问题**：修改过程中是否引入了新的逻辑bug或AI味

### 版本进步评估

```
初稿 62分(C) → 修改稿 78分(B) → 终稿 91分(A)
```

如果修改稿分数没有提升或反而下降，标记为"修改无效"，升级处理。

---

## 升级处理机制

以下情况需要升级处理（主审自己决策，不是给写手的）：

| 情况 | 升级动作 |
|------|----------|
| 写手连续3次C级 | 考虑更换写手或降级项目复杂度 |
| 修改后分数不升反降 | 直接电话/语音沟通，文字指导已失效 |
| 全本终审发现大面积AI跑飞 | 退回要求人工重新过一遍，不接受纯AI产出 |
| 交付期限临近但质量不达标 | 判断是小改能救还是需要换人/延期 |
| 写手对同一问题反复犯错 | 把该问题加入该写手的"重点监控项" |

## 审稿数据追踪

每次审稿后记录以下数据（用于复盘和写手管理）：

```markdown
| 日期 | 项目 | 写手 | 模式 | 阶段 | 等级 | 分数 | 主要问题 | 修改次数 |
```

### 周度复盘用数据

- 本周审了多少本
- 通过率（A+B占比）
- 最常见退稿原因TOP3
- 哪些写手需要关注
- 哪些题材方向通过率高

## 审稿心理原则

- **对稿不对人**：批注就事论事，不写"你怎么又犯这个错"
- **先肯定方向再指问题**：哪怕C级也先说"方向/题材/某个设定是对的"
- **给写手信心**：修改意见要让写手知道"改完就能过"，而不是"你这个烂透了"
- **标出亮点**：看到写得好的台词/设计好的反转，在报告里标注"这里写得好"
- **修改意见克制**：一次最多给5-7条修改，太多了写手会崩，按优先级排

## 完整审稿流程（汇总）

```
收到稿件
  │
  ├─ 确认：模式 + 阶段 + 写手等级
  │
  ├─ 30秒快速淘汰（K1-K5）
  │     ├─ 命中 → 调用模板编号，秒退，出简短退稿理由
  │     └─ 不命中 → 进入正式审稿
  │
  ├─ 正式审稿（根据写手等级调整深度）
  │     ├─ 题材匹配
  │     ├─ 材料完整性
  │     ├─ 格式合规
  │     ├─ 节奏爽感（重点）
  │     ├─ 逻辑连贯
  │     ├─ 上下文衔接
  │     ├─ 人设一致
  │     ├─ 台词自然度（重点）
  │     ├─ 画面可拍性
  │     └─ AI生成痕迹
  │
  ├─ 打分 + 定级（A/B/C/D）
  │
  ├─ 输出
  │     ├─ 主审内部判断（给自己看）
  │     ├─ 分项评分表
  │     ├─ 必改问题 + 建议优化
  │     └─ 给写手的修改意见（可直接复制发出）
  │
  └─ 记录审稿数据
```
