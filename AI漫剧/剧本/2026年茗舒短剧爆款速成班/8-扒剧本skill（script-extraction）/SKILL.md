# script-extraction

> 归属：茗舒

用于把短剧视频、字幕、逐字稿、截图还原成甲方投稿格式剧本。

## 必须触发

用户说"扒剧本""扒一下""批量视频转剧本""按投稿格式""先输出第一集核对"等，必须按本技能执行。

## 锁定工作流

### 阶段一：准备（每部剧只做一次）

1. **建时间轴**：用 faster-whisper medium（vad_filter=False）转写每集音频，生成 Whisper 时间轴。
2. **OCR 校正**：EasyOCR 抽底部硬字幕 + 人名条/身份条，生成 OCR 备选。
3. **合并 clean timeline**：将 Whisper + OCR 合并为 `ep{XX}_clean.txt`，格式：
   - `[起始-结束] 台词文字`
   - `(OCR备选: XXX conf=X.XX)` — 置信度高时优先采用
4. **建角色指南**：批量前先建 `character_guide.md`，包含：
   - 每个角色：身份变化、自称、称呼他人、说话特征、关键台词
   - 剧情分幕概要（按 5-10 集为一段）
   - 用于子代理快速判断说话人
5. **建校正规则文件**：创建 `script_rules.md`，包含：
   - 输出格式规范
   - 分场规则
   - 该剧 Whisper 常见误识别对照表（每部剧不同，开几集后即可整理）
   - 角色识别速查表
   - 质量红线

### 阶段二：样稿验收

6. **先出样稿**：输出第 1 集（或用户指定集），确认格式、台词密度、人物归属、动作颗粒度。
7. **用户确认后锁定标准**，后续批量按此标准执行。

### 阶段三：批量生产

8. **子代理批量模式**（节省 token 的关键）：
   - 每个子代理处理 3-4 集
   - 子代理 prompt 只包含：读 rules 文件指令 + 读样稿指令 + 本批时间轴 + 说话人归属
   - 规则、格式、校正表等通过文件引用，不内联重复
   - 同时调度 3 个子代理并行处理
9. **质量验证**：优化 prompt 后，先跑 1 集对比样稿确认质量，再放量批量。

### 阶段四：交付核查

10. 检查文件数量是否齐全
11. 抽查 2-3 集对比样稿质量

## 投稿格式

场景格式：`场X-X：第X集第X个场景 / 日或夜 / 内或外 / 地点`
下一行：`人物：XXX、XXX`
动作行：以 `△` 开头，只写画面能看到的动作。
台词行：`角色名：台词` 或 `角色名（状态/动作）：台词`
特殊标记：`VO`=旁白，`OS`=内心独白，`VO/回忆`=回忆闪回中的声音。

## 说话人归属规则

**有人名条的剧**：说话人优先以画面人名条/身份条/OCR 为准，不能只凭台词内容猜。拿不准写 `【身份待核】`。

**无人名条的剧**：靠角色指南归属——
- 自称匹配（"本太子""臣""朕""本宫""奴婢"）
- 称呼关系（谁叫谁什么）
- 说话语气/特征
- 上下文对话逻辑（A 说完 B 回应）
- 必须在子代理 prompt 中逐集写明说话人归属，不能让代理自己猜

## 不补不存在内容

- 没有字幕或画面不能确认的，不硬写台词、不脑补动作、不提前写身份
- 每一集只写本集时间码画面中真实出现的内容，不把上一集结尾串进下一集

## Token 优化原则

1. **规则文件化**：格式规范、校正表、角色速查表写入 `script_rules.md`，子代理读文件而非内联
2. **批量合并**：每个子代理处理 3-4 集，减少代理启动开销
3. **并行调度**：无依赖的子代理同时启动（通常 3 个并行）
4. **prompt 精简**：说话人归属只写当批集数的，不传全剧
5. 首次验证通过后再放量，避免返工浪费

## 项目锁定标准

### 《将军请自重》（81集）

用户已确认第 1 集重做版"可以"，后续 2-81 集按此标准继续：

- 开场 VO 要逐句保留，如"我叫薛玉""是裴家的寡嫂""小叔子从军"等。
- 画面动作简洁贴画面，不写心理分析，不补看不到的调度。
- 台词按 OCR 字幕 + Whisper 时间轴双校，不漏短句。
- 无字幕结尾只写可见画面，身份未确认写 `【身份待核】`。
- 必须先建时间轴再成稿。
- 每一集只写本集时间码画面中真实出现的动作。

### 《休夫后，她回家继承帝位》（80集）— 已完成

用户已确认第 1 集质量标准，80 集全部按此标准完成：

- 该剧无画面人名条，说话人靠角色指南 + 对话逻辑归属
- Whisper 常见误识别：南赵→南诏、裴子严→裴子琰、萧清雪→萧倾雪、齐渊→祁渊、果果→国库、和谊→和离、萧綦荒→萧祁凰、庸朝→雍朝、义旨→懿旨
- 工作文件位于 `D:/script_work/`（clean timeline、角色指南、校正规则）
- 成稿位于 `D:/扒剧本_休夫后她回家继承帝位/`
