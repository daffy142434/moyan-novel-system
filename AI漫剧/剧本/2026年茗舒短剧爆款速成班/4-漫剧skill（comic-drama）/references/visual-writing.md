# 漫剧画面写作规范

## 核心原则：Show, Don't Tell

漫剧没有真人演员，画面完全靠AI生成。剧本的△描写就是"导演的眼睛"——写什么，观众就看到什么。

**铁律**：不要告诉观众角色在想什么或感受什么，要展示能让观众自己感受到的画面。

| ❌ 告诉（短剧写法） | ✅ 展示（漫剧写法） |
|---------------------|---------------------|
| 他很愤怒 | 指节捏得发白，额角青筋暴起，桌面被拍出裂纹 |
| 她很伤心 | 雨水顺着脸颊滑落，分不清是泪还是雨，手中的信纸被打湿模糊 |
| 他很紧张 | 喉结上下滚动，额头渗出细密的汗珠，手指在袖中微微发抖 |
| 气氛很压抑 | 阴云压顶，树叶纹丝不动，空气仿佛凝固，远处传来乌鸦的叫声 |
| 他实力很强 | 仅仅抬手，对面三人已经被气浪掀飞，撞穿了身后的石墙 |

## 视觉情绪对照表

写漫剧剧本时，用这张表将抽象情绪映射为具体画面：

### 愤怒系

| 程度 | 画面表现 |
|------|----------|
| 隐忍 | 握拳，指甲掐入掌心，手背青筋浮起 |
| 爆发前兆 | 瞳孔收缩，呼吸急促可见胸腔起伏，周围空气开始扭曲 |
| 全面爆发 | 怒吼，气浪以身体为中心向外扩散，地面龟裂，碎石漂浮 |

### 震惊系

| 程度 | 画面表现 |
|------|----------|
| 微惊 | 瞳孔微张，手中的动作停顿一瞬 |
| 震惊 | 眼睛圆睁，手中的物品脱手掉落（慢动作），嘴唇微张 |
| 极致震撼 | 双膝发软后退一步，画面出现短暂的失焦然后重新对焦 |

### 悲伤系

| 程度 | 画面表现 |
|------|----------|
| 隐痛 | 低下头，刘海遮住眼睛，肩膀微微塌下 |
| 心碎 | 泪水无声滑落，手指无力地松开某个重要物品 |
| 绝望 | 跪倒在地，双手撑地，雨水/雪花落满肩头，周围色调变灰 |

### 觉醒/爆发系（漫剧高频场景）

| 程度 | 画面表现 |
|------|----------|
| 初始觉醒 | 瞳孔变色（金/红/紫），皮肤下浮现发光纹路 |
| 力量涌出 | 头发飘起，衣袂猎猎，脚下地面出现裂纹，光芒从体内涌出 |
| 完全释放 | 身后出现虚影（龙/凤/法阵），能量化为实质向四周扩散 |

### 霸气/碾压系

| 程度 | 画面表现 |
|------|----------|
| 淡定碾压 | 表情不变，仅用一根手指挡住对方全力一击 |
| 气势压制 | 眼神扫过，目光所及之处的人不由自主后退，空气肉眼可见地扭曲 |
| 绝对碾压 | 随手一挥，对手的武器碎裂，人像断线风筝般飞出画面 |

## 环境即情绪

漫剧可以用环境来强化情绪表达，这是真人短剧做不到或成本极高的优势：

| 情绪 | 环境表现 |
|------|----------|
| 压抑/危机 | 阴云密布、色调偏冷偏暗、风沙、枯枝 |
| 逆袭/爆发 | 金光万丈、云开雾散、色调从灰暗骤变为明亮 |
| 甜蜜/温馨 | 樱花/花瓣飘落、暖色阳光、柔焦背景 |
| 恐惧/悬疑 | 浓雾、影子拉长、光源摇曳不定、色调偏绿偏青 |
| 孤独/寂寞 | 空旷场景、主角渺小的身影、冷色月光 |
| 终极对决 | 天地变色、雷电交加、地面崩裂、两股能量对冲 |

写法示例：
- ❌ "气氛变得紧张起来"
- ✅ "天边的乌云压低，远处传来沉闷的雷声。风骤然停了，树叶凝固在半空"

## 画面颗粒度拆分

### 什么时候需要精细拆分

同样一段剧情，拆成多个短画面比写成一个长画面更利于AI生成。但不是所有地方都需要拆——只在关键场景精细化。

**必须精细拆分的场景**：
- 爽点高潮（身份揭露、打脸、逆袭、觉醒爆发）——这些是全剧的"钱景"
- 复杂动作序列（打斗、追逐、特效爆发）——AI最容易翻车的地方
- 情绪重大转折（从隐忍到爆发、从绝望到希望）——需要渐进表现

**不需要拆分的场景**：
- 普通对话和过渡
- 简单的走路、坐下、环顾等日常动作
- 环境交代

### 精细画面的写法

用 `△ 【精细画面】标题` 标记开始，每个画面节拍用 `---` 分隔。每个节拍就是一个可独立生成的画面单元（对应Seedance的5秒/10秒/15秒生成时长）。

```
△ 【精细画面】灵根觉醒

△ （近景）林风双膝跪地，双手撑着地面，额头汗珠滚落。
  手背上的青筋突起，指缝间的泥土被捏碎。

---

△ （特写）林风的手背——皮肤下突然浮现一道金色纹路，
  像闪电一样从手腕蔓延到指尖，微光脉动。

---

△ （中景）金色光芒从林风全身涌出，头发被气流扬起，
  衣袂猎猎飘动。他缓缓站起，双眼已变成纯金色。

---

△ （全景）光芒化为冲击波向四周扩散，地面的落叶和碎石
  被气浪卷飞，围攻的黑衣人纷纷后退踉跄。
```

### 普通画面的写法

不加精细标记，按正常段落书写：

```
△ （中景）林风推开木门走进客栈，环顾四周，
  找了个角落的位置坐下，对小二招了招手。
```

### 节拍的设计原则

- 每个节拍只描述一个简单动作或一个画面状态变化
- 每个节拍的内容在5秒视频时长内可以完成
- 如果一个节拍的动作太复杂（AI可能做不好），就继续拆
- 节拍之间的衔接要自然——上一个节拍的结束状态就是下一个节拍的起始状态

## 漫剧专属标记

在原有标记基础上（△、【】、♪、☎），新增以下漫剧专属标记：

| 标记 | 含义 | 示例 |
|------|------|------|
| 🎨 | 视觉风格提示 | 🎨 水墨风留白构图 |
| ⚡ | 特效描述 | ⚡ 灵根觉醒金光涌出 |
| OS | 角色内心独白 | OS：（林风内心）这一次，我不会再退让 |
| VO | 画外音/旁白 | VO：（低沉旁白）三千年前，天地初开…… |

这些标记是辅助信息，帮助阅读者快速识别场景类型，不影响剧本的阅读流畅度。

## 景别使用原则（漫剧特化）

| 景别 | 漫剧中的适用场景 | 使用频率 |
|------|-------------------|----------|
| 全景/远景 | 世界观展示、大场面、战斗全貌、环境渲染 | 每集3-5次 |
| 中景 | 对话、互动、常规叙事 | 最高频 |
| 近景 | 情感表达、重要对话、反应 | 高频 |
| 特写 | 情绪爆发、关键物件、表情细节、觉醒/变化 | 爽点必用 |

漫剧特别注意：
- 觉醒/爆发类场景，推荐「特写→中景→全景」的景别递进——先看细节变化，再看整体效果
- 打脸类场景，推荐「近景（反派嚣张）→特写（主角表情）→全景（碾压画面）」
- 不要连续多个同景别画面——景别变化本身就是节奏
