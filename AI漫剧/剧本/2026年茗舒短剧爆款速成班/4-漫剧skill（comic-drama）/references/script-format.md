# 漫剧剧本格式规范

## 完整格式模板（中文版）

```
剧名：《剧名》
集数：第X集  标题
视觉风格：{项目设定的风格}

════════════════════════════════════════

场次 X-1：内/外  具体地点  日/夜
────────────────────────────────────────
出场人物：角色1；角色2；角色N

△ （全景）场景环境描写。用有画面感的文字构建场景，
  服务于该风格的美学特征。注重光影和氛围。

角色1
（语气或动作描写）
台词内容。

△ （近景）角色2的动作和表情变化。
  漫剧的△描写要比真人短剧详细——展示而非告知。

角色2
（语气或动作描写）
台词内容。

△ 【精细画面】高潮场景标题

△ （特写）第一个画面节拍描述。
  简单动作，5秒内可完成。

---

△ （中景）第二个画面节拍描述。
  承接上一个节拍的结束状态。

---

△ （全景）第三个画面节拍描述。
  展现整体效果。

⚡ 特效描述（如有）

♪ 音乐/音效提示

────────────────────────────────────────

场次 X-2：内/外  具体地点  日/夜
────────────────────────────────────────
（继续……）

════════════════════════════════════════
本集完 ｜ 下集预告：一句话悬念钩子
本集画面节拍统计：共XX个（精细画面X个，常规画面X个）
```

## 格式要素详解

### 1. 场景头

```
场次 [集数]-[场次序号]：[内/外]  [具体地点]  [日/夜]
```

### 2. 出场人物

紧跟场景头，用分号分隔。只列本场次实际出场角色。

### 3. 动作/画面描写（△标记）

漫剧的△描写是整个剧本的核心，遵循 visual-writing.md 的写作规范：
- 使用Show, Don't Tell原则
- 注重画面感、光影、质感描写
- 匹配选定的视觉风格美学
- 关键场景使用精细画面拆分
- 每段△不超过3行（精细画面的每个节拍不超过3行）
- 保持AI画面可行性意识

### 4. 景别提示

在△段落中用括号标注：

| 景别 | 适用场景 |
|------|----------|
| （全景）/（远景） | 环境交代、大场面、世界观展示 |
| （中景） | 对话、互动、常规叙事 |
| （近景） | 情感表达、重要对话 |
| （特写） | 情绪爆发、关键物件、觉醒/变化 |

### 5. 角色台词

三行结构：

```
角色名
（语气/动作指示）
台词正文。
```

漫剧台词要求：
- 单句不超过25字（比真人短剧更短——漫剧靠画面，不靠台词）
- 爽点台词要简短有力，适合截图传播
- 避免长篇解释性台词——需要交代的信息用VO旁白或画面展示
- 男频台词风格：霸气、冷酷、简短。避免女性化语气词

### 6. 精细画面格式

用 `△ 【精细画面】标题` 标记，用 `---` 分隔节拍。详见 visual-writing.md。

### 7. 特殊标记

| 标记 | 含义 | 示例 |
|------|------|------|
| △ | 动作/画面描写 | △ 主角缓缓站起 |
| （） | 语气/动作指示 | （冷笑） |
| 【】 | 画外音/旁白 | 【旁白】千年前…… |
| ♪ | 背景音乐/音效 | ♪ 紧张悬疑鼓点渐起 |
| ☎ | 通讯/传音 | ☎ 传音符震动 |
| OS | 内心独白 | OS：（林风）这一次不一样了 |
| VO | 画外旁白 | VO：（低沉）三千年前…… |
| 🎨 | 视觉风格提示 | 🎨 水墨留白构图 |
| ⚡ | 特效描述 | ⚡ 金色灵力化为龙形 |

### 8. 每集结构规范

| 位置 | 时长 | 内容要求 |
|------|------|----------|
| 开场 | 前30秒 | 引爆冲突/悬念，承接上集 |
| 发展 | 1-1.5分钟 | 冲突升级、反转叠加 |
| 高潮 | 30-45秒 | 爽点释放（建议使用精细画面） |
| 钩子 | 最后10秒 | 悬念留住观众 |

每集要求：
- 总字数≥800字
- 3-5个场次
- 至少2个爽点或反转
- 至少1个精细画面场景
- 结尾必须有悬念钩子
- 末尾附「画面节拍统计」

## 格式示例（3D CG渲染风格）

```
剧名：《废柴神脉》
集数：第1集  灵根觉醒
视觉风格：3D CG渲染

════════════════════════════════════════

场次 1-1：内  皇宫·冷殿  晨
────────────────────────────────────────
出场人物：林风；宫女阿绿

△ （全景）破败的宫殿，屋顶的琉璃瓦碎了一半，
  晨光从残破的窗棂间挤进来，在灰尘中拉出金色的光柱。
  墙角结着蛛网，一张简陋的木床上躺着一个少年。

△ （特写）少年的眼睛猛然睁开——瞳孔中有一瞬间
  闪过金色的微光，转瞬即逝。额头上冷汗密布。

林风
（喘息，按住胸口）
又是那个梦……

△ （近景）林风坐起身，低头看着自己的手。手指修长但苍白，
  手背上隐约有一条细如发丝的金色纹路，一闪而过。
  他揉了揉眼睛，纹路消失了。

♪ 远处传来宫钟的沉闷声响

阿绿
（端着一碗粥推门进来，语气心疼）
殿下，今日的试炼……要不装病吧？

林风
（平静地接过粥碗）
躲得了今天，躲不了明天。

────────────────────────────────────────

场次 1-2：外  皇宫·试炼广场  日
────────────────────────────────────────
出场人物：林风；大皇子李昊；二皇子李渊；国师；围观众人

△ （远景）宏大的试炼广场，青石铺地，四周飘着写有
  "灵根试炼"的锦旗。百余名皇室子弟和宗门弟子站成方阵。
  高台上，国师盘坐在灵石阵中央。

△ （中景）林风穿着洗得发白的灰蓝色袍子走进广场，
  在一群锦衣华服的皇子中间格格不入。

李昊
（翘着二郎腿坐在VIP席位，弹了弹指甲）
哟，废物七弟也来了？你那破灵根，测出来不怕丢人？

△ 全场哄笑。林风的脚步没有停，目光平视前方。

李渊
（阴阳怪气）
大哥别说了，七弟好歹是来给我们凑个数嘛。

△ 【精细画面】灵根觉醒

△ （中景）林风走到灵石前，深吸一口气，双手按上灵石。
  灵石表面毫无反应。全场嘲笑声更大了。

---

△ （特写）林风的手指——指尖与灵石接触的位置，
  石头表面突然出现一道细微的裂纹。

---

△ （特写转中景）裂纹从灵石内部迅速扩散，金色的光芒
  从裂纹中涌出。林风的瞳孔骤然变成纯金色。

---

△ （全景）灵石炸裂，金色光柱冲天而起，照亮了整个广场。
  所有人被气浪逼退一步，衣袍猎猎飞舞。
  笑声戛然而止。

⚡ 金色光柱中隐约浮现一条盘旋的龙影

♪ 震撼的鼓点骤然响起

△ （近景）国师猛地睁开眼，双手颤抖，
  从座位上站了起来。

国师
（声音颤抖）
这……这是远古神脉！

△ （特写）李昊的笑容僵在脸上。手中的茶杯碎裂，
  茶水洒了一身，他浑然不觉。

════════════════════════════════════════
本集完 ｜ 下集预告：觉醒的代价远比想象中沉重——
当整个皇宫都知道七皇子不再是废物，最先动手的不是敌人，
而是最亲近的人。
本集画面节拍统计：共18个（精细画面4个，常规画面14个）
```

## 英文格式（出海模式）

当用户选择英文输出时，切换为好莱坞行业标准格式。核心创作原则不变，仅格式调整：

| 元素 | 中文格式 | 英文格式 |
|------|---------|---------| 
| 场景头 | 场次 1-1：内 办公室 日 | SCENE 1-1: INT. OFFICE — DAY |
| 内/外 | 内 / 外 | INT. / EXT. |
| 出场人物 | 出场人物：角色A | Cast: Character A |
| 景别 | （全景）（中景）（近景）（特写） | (WIDE) (MEDIUM) (CLOSE-UP) (EXTREME CU) |
| 精细画面 | △ 【精细画面】 | △ 【DETAILED SEQUENCE】 |
| 节拍分隔 | --- | --- |
| 画外音 | VO：旁白 | VO: narration |
| 集尾 | 本集完 | END OF EPISODE |
