# 分集撰写要求与自检清单（漫剧版）

## 撰写流程

### 写前准备

每次撰写分集前，先确认：

1. **上集结尾**：上一集的最后一个画面和钩子是什么
2. **本集定位**：在全剧节奏中属于什么阶段
3. **本集核心**：这一集要完成什么（核心冲突/爽点/转折）
4. **精细画面预判**：本集有哪些场景需要精细化处理
5. **下集衔接**：本集结尾要为下一集铺什么悬念

### 撰写步骤

1. 先写本集的节奏骨架（3-5个场次的一句话概述）
2. 标记哪些场景需要精细画面处理
3. 展开每个场次，按漫剧格式规范撰写
4. 检查画面描写是否匹配选定的视觉风格
5. 检查AI画面可行性（有无红灯画面）
6. 统计画面节拍数量
7. 通读确认节奏流畅

## 分集撰写要求

### 基础要求

- 每集字数≥800字
- 每集3-5个场次
- 严格遵循漫剧剧本格式（见 script-format.md）
- 遵循漫剧画面写作规范（见 visual-writing.md）
- 保持AI画面可行性意识（见 ai-awareness.md）
- 每集至少1个精细画面场景

### 画面描写要求（漫剧核心）

- △描写以Show, Don't Tell为铁律
- 每个△段落不超过3行
- 用视觉情绪对照表将抽象情绪映射为具体画面
- 环境描写服务于情绪表达
- 匹配选定的视觉风格美学特征
- 爽点/高潮场景必须使用精细画面拆分

### 台词要求

- 单句不超过25字（漫剧靠画面，台词要精炼）
- 每句台词必须推动剧情或揭示人物
- 爽点台词简短有力，适合截图传播
- 男频台词：霸气、冷酷、简短，避免女性化语气词
- 不同角色说话方式有区分度
- 需要交代的背景信息用VO旁白，不要塞进对话

### 节奏要求

- 快节奏第一原则
- 跳跃式叙事，不拘泥于场景过渡
- 大量使用跳切
- 连续3集没有强爽点 = 节奏出了问题

### 精品化写作要求

- 每个反转和爽点必须有合理铺垫
- 角色动机要可信
- 画面描写有构图意识和美学追求
- 台词有记忆点和角色辨识度
- 全程高强度中适当穿插"呼吸感"

### 固定桥段活用（漫剧特化）

| 桥段 | 漫剧视觉表现 |
|------|-------------|
| 觉醒爆发 | 光芒涌出、瞳孔变色、头发飘起、地面龟裂——用精细画面拆分 |
| 实力碾压 | 一指弹开对方攻击、气浪震飞全场——注重力量对比的视觉反差 |
| 身份揭露 | 印记/纹路浮现、天降异象、所有人震惊后退——强调围观者反应 |
| 进化/升级 | 身体发光变化、外形蜕变、新形态展示——用多个节拍分步展示 |
| 至暗时刻 | 色调变灰暗、环境崩塌、主角跪倒——环境即情绪 |
| 终极对决 | 两股能量对冲、天地变色、终极一击——全剧最华丽的精细画面 |

## 特殊集数撰写指南

### 第1集：爆炸开场

- 第一个画面就要抓人——漫剧观众比真人短剧观众更没耐心
- 30秒内建立主角困境和视觉奇观
- 建议开篇就包含一个精细画面场景（如觉醒前兆、战斗开场）
- 结尾留超强钩子

### 付费卡点集（第8-12集）

- 所有铺垫汇聚
- 最华丽的视觉场景
- 情绪推到最高点后戛然而止
- 建议2-3个精细画面场景

### 至暗时刻集（第35-40集）

- 色调和环境描写转为压抑暗沉
- 主角的视觉形象出现变化（受伤、狼狈、力量失控）
- 在绝望中埋下反击种子

### 大结局集（最后2-3集）

- 全剧最华丽的视觉盛宴
- 终极对决用最多的精细画面节拍
- 所有悬念收回
- 最后一个画面要有"余韵"

## 自检清单

每集写完后，逐项检查：

### 节奏检查 ✅

- [ ] 开场30秒内引爆冲突？
- [ ] 自然承接上集钩子？
- [ ] 有无拖沓段落（超过30秒无冲突/信息）？
- [ ] 结尾钩子够强？

### 爽点检查 ✅

- [ ] 本集≥2个爽点或反转？
- [ ] 爽点强度与全剧进度匹配？
- [ ] 爽点前有足够铺垫和压抑？

### 画面描写检查 ✅

- [ ] △描写是否遵循Show, Don't Tell？
- [ ] 画面描写是否匹配选定的视觉风格？
- [ ] 是否使用了视觉情绪对照表而非抽象情绪词？
- [ ] 环境描写是否服务于情绪表达？
- [ ] 爽点/高潮场景是否使用了精细画面拆分？

### AI画面可行性检查 ✅

- [ ] 有无红灯画面（复杂多人同时运动、手指特写、文字特写等）？
- [ ] 黄灯画面是否已简化或拆分？
- [ ] 每个精细画面的节拍是否足够简单（单一动作、5秒可完成）？
- [ ] 精细画面的节拍之间衔接是否自然？

### 台词检查 ✅

- [ ] 有无超过25字的长台词？
- [ ] 每句台词是否推动剧情？
- [ ] 不同角色说话风格有区分？
- [ ] 背景信息是否用了VO旁白而非对话？

### 格式检查 ✅

- [ ] 场景头完整（内/外、地点、日/夜）？
- [ ] 出场人物列齐？
- [ ] 关键画面标注了景别？
- [ ] 字数≥800字？
- [ ] 末尾有画面节拍统计？

### 连贯性检查 ✅

- [ ] 角色行为符合设定？
- [ ] 角色视觉锚点（服装、配饰）前后一致？
- [ ] 与前面已写的集数无矛盾？
- [ ] 时间线通顺？

### 镜头密度估算

每集完成后统计：
- 总画面节拍数：XX个
- 其中精细画面节拍：XX个
- 常规画面节拍：XX个
- 预估视频总时长：约X分X秒（按每节拍5秒估算，精细画面按标注时长估算）

此数据帮助评估制作工作量和排期。

## 批量撰写建议

- 每5集做一次小回顾：角色弧线是否推进、视觉锚点是否一致
- 每10集做一次节奏校准：情绪曲线是否符合全剧规划
- 付费卡点前后3集特别精心
- 建议每次撰写1-3集，确认满意后再继续
