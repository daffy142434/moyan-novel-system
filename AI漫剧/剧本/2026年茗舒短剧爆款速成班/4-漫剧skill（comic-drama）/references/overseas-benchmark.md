# 海外漫剧质量标杆 · Alpha's Vengeance

> 本文件为海外原创漫剧的**质量参考**，写海外漫剧时对标此样稿的内容密度、冲突设计、人物塑造水准。格式仍按 script-format.md 标准输出。

## 基本信息

- 剧名：《Alpha's Vengeance》（狼王嫡女复仇录）
- 对标：《出狱当天，世间再无我》
- 题材：奇幻狼人、嫡女蒙冤复仇
- 元素：贵族狼人家族、牢狱伤残、全员恶人原生家庭、暗中取证、神秘强者单向守护、家族阴谋、人命血债、公开族群审判、推翻千年旧制
- 篇幅：60集，每集1-3min

## 质量标杆要点（写海外漫剧必须达到的水准）

### 1. 女主独立人设（核心差异化）
- 天狼尊主拥有碾压全族实力，多次提出替女主扫平仇敌，均被女主拒绝
- 坚持依靠自己搜集完整人证物证亲手翻案，拒绝依附强者
- **编剧要求**：女主永远是剧情推动者，男主是辅助/兜底，不是拯救者

### 2. 多层冲突密集爽虐交织
- 出狱后全家排挤虐待
- 继妹屡次设计加害
- 父母颠倒黑白
- 兄长胁迫牵制
- 前未婚夫仇视误解
- **编剧要求**：每集至少2层冲突叠加，虐点压抑要有明确的后期爽感释放对应

### 3. 完整线索闭环
- 已故忠仆Mary串联全部剧情：女主唯一温情依靠 + 男女主相遇契机 + 家族罪证持有者
- 昏迷少女Evie：构陷女主的关键道具，后期苏醒完成真相闭环
- **编剧要求**：每个角色/道具必须承担多重叙事功能，拒绝工具人

### 4. 神秘男主（克制深情型）
- 百年隐世，因早年被Mary救下
- 多年默默守护女主，全程不干预女主复仇计划
- 仅在女主生死关头现身兜底
- **编剧要求**：男主戏份克制，每次出现必须推动剧情或提升情感张力

### 5. 格局跳出私仇
- 不止洗刷个人冤屈
- 最终揭露贵族抽取纯血狼核续命的千年陋习
- 联手废除残酷族群旧规
- **编剧要求**：个人复仇必须升维到群体/社会层面，提升故事厚度

### 6. 节奏密度参考（前10集）
- 1-3集：蒙冤归巢 + 初识守护者 + 立复仇誓言 + 第一次取证 + 第一次生死危机
- 4-6集：持续取证 + 家族内讧 + 男女主拉扯加深
- 7-8集：反派反击 + 新陷害 + 女主应对
- 9集：证人动摇 + 真相初露
- 10集：诱杀圈套 + 生死cliffhanger

**每3集一个小高潮，每集多重冲突叠加，绝不允许"过渡集"存在。**

### 7. 画面描写密度参考
- △描写具体到动作细节：「假肢摩擦残肢，撕裂出血，血迹一路落在地面」
- △环境必须服务情绪：「厚重的银钉铁门，墙面积满狼血的痕迹，远处的囚徒哀嚎不绝」
- △表情/身体语言替代心理描写：「狼耳慌乱下垂，捂住口袋里的镇静剂药瓶，眼神惊惧」

### 8. 台词标杆
- 爽点台词简短有力：「我的冤，我的仇，我会亲手清算，不需要外人帮扶。」
- 反派台词要狠要具体：「五年银刑期满，快滚！若再踏进荒原，就让你银笼剥皮！」
- 男主台词克制温柔有力量感：「我在外等了你很久，为何不喊我的名字？」

## 海外女频爆款公式总结

```
蒙冤/受辱女主 + 独立复仇人设 + 克制深情男主暗中守护 
+ 多层反派轮番加害 + 完整证据链闭环 + 私仇升维族群公义
```
