# AI画面可行性意识

## 概述

本模块为编剧在「写剧本阶段」提供AI视频生成能力边界的意识指导。目标是从源头减少不可执行的镜头描述，提升下游制作效率。

注意：这里是编剧层面的"意识"指导，不是精确的技术规范。精确的平台规范（如Seedance 2.0的提示词长度、@引用系统、运镜写法等）由下游的AI视频分镜师团队Agent负责。

本Skill主要适配两个AI视频生成平台：Seedance 2.0（主力）和可灵3.0（备选）。

## 绿灯画面（优先使用）

以下画面类型是当前AI视频模型的强项，编剧可以放心大胆地写：

| 画面类型 | 说明 | 示例 |
|----------|------|------|
| 静态人物特写 | 人物面部表情、情绪变化 | "瞳孔收缩，嘴角微微上扬" |
| 简单单人动作 | 走、跑、转身、抬手、站起、坐下 | "缓缓站起身，拂去肩上的灰尘" |
| 环境氛围渲染 | 天气、光影、自然景观 | "晨雾未散，远山若隐若现" |
| 光影变化 | 从暗到亮、逆光、光束 | "阳光从云层间倾泻而下" |
| 特效/能量表现 | 发光、气流、粒子效果 | "金色灵力从掌心涌出" |
| 物件特写 | 信件、武器、饰品等 | "古剑的剑身上浮现出神秘铭文" |
| 表情渐变 | 情绪的缓慢变化 | "从震惊到释然，嘴角逐渐放松" |
| 风/水/火等自然元素 | 自然力的视觉表现 | "火焰在掌中跳动，照亮了他的脸" |

## 黄灯画面（可以写，但要简化）

以下画面AI可以生成，但成功率不如绿灯画面，建议简化描述或拆分成多个绿灯画面：

| 画面类型 | 风险点 | 建议处理 |
|----------|--------|----------|
| 两人互动 | 两人的动作容易不协调 | 每个画面聚焦一个人，切镜头表现互动 |
| 中等复杂打斗 | 动作连贯性难保证 | 拆成多个5秒短镜头，每段只做一个动作 |
| 动物/生物 | 形态可能不稳定 | 减少运动幅度，多用静态或缓慢动作 |
| 群体场景（3-5人） | 人物容易变形或融合 | 用全景/远景，不要求每个人的细节 |
| 快速运动 | 容易产生拖影或变形 | 用暗示代替直接展示，或拆成起始+结果 |

## 红灯画面（避免或改写）

以下画面类型是当前AI视频模型的短板，编剧应避免直接描写，改用等效替代方案：

| 红灯画面 | 为什么做不好 | 替代方案 |
|----------|-------------|----------|
| 复杂多人同时运动 | 模型难以同时控制多个运动主体 | 分切多个单人/双人镜头交叉剪辑 |
| 精确手指动作 | 手指细节是AI通病 | 用中景或远景避开手部特写，或改为握拳/挥手等大动作 |
| 文字特写（信件、书本） | AI生成的文字几乎都是乱码 | 用VO旁白读出内容，画面只拍"拿着信的手"而非信上的字 |
| 远距离连续追逐 | 长时间运动场景一致性差 | 拆成多段短镜头：追→跑→追上→对峙 |
| 空中连续翻转 | 复杂空间运动几乎不可控 | "身影从高处一跃而下"→切镜头→"稳稳站在地面" |
| 精确的唇形对口型 | 中文对口型效果不稳定 | 重要台词用近景（不是特写），或配合VO处理 |
| 镜子中的倒影 | 镜像一致性差 | 避免镜子剧情，改用水面模糊倒影 |
| 同一角色不同年龄 | 跨年龄一致性差 | 用不同镜头分别展示，靠旁白或字幕交代是同一人 |

## 替代写法速查

### 场景一：主角从悬崖跳下精准落马

❌ 原始写法：主角从悬崖跳下，在空中连续翻转三圈后精准落在马背上

✅ 替代写法（拆成3个画面节拍）：
- 节拍1：主角站在悬崖边，衣袂飘动，向下纵身一跃
- 节拍2：俯拍，人影急速下坠，风声呼啸
- 节拍3：马背上，主角已经稳稳坐好，拉住缰绳，马嘶鸣

### 场景二：多人围攻主角的混战

❌ 原始写法：十个黑衣人同时向主角冲来，主角一一闪避并反击

✅ 替代写法（分切表现）：
- 节拍1：（全景）十个黑影从四面八方逼近主角
- 节拍2：（近景）第一人挥刀砍来，主角侧身闪过，一掌拍在对方胸口
- 节拍3：（中景）又两人从背后偷袭，主角脚下一转，气浪将两人震开
- 节拍4：（全景）尘烟散去，十人全部倒地，主角站在中央，衣角微动

### 场景三：角色读信然后大怒

❌ 原始写法：主角拿起信件，看到上面写着"你的父亲已经死了"，勃然大怒

✅ 替代写法：
- △（近景）主角拆开信封，目光扫过信纸。
- VO：（低沉旁白）"你的父亲已经死了。"
- △（特写）主角的手开始颤抖，信纸被捏出褶皱。
- △ 信纸从手中滑落飘向地面（慢动作）。

## Seedance 2.0 与 可灵 3.0 的差异提示

两个平台都能执行上述绿灯画面，但在某些方面有差异：

| 维度 | Seedance 2.0 | 可灵 3.0 |
|------|-------------|----------|
| 单次最长时长 | 15秒 | 10秒 |
| 角色一致性 | 通过@Image引用保持 | 通过参考图保持 |
| 动作流畅度 | 优秀 | 优秀 |
| 多人场景 | 建议单一主体 | 支持双人但效果递减 |
| 特效表现 | 优秀（能量、光效） | 优秀（自然元素） |
| 音频同步 | 原生支持 | 需后期配音 |

编剧层面不需要针对某个平台特别调整写法——只要遵循上述绿灯/黄灯/红灯原则，产出的剧本在两个平台都能跑通。平台层面的精细适配是下游Agent的职责。

## 编剧自检提示

写完每个△描写后，快速过一遍这三个问题：
1. 这个画面是一个简单动作还是复杂连续动作？（复杂→拆分）
2. 画面中有几个运动主体？（超过2个→简化或分切）
3. 有没有手指特写或文字特写？（有→改写）

养成这个习惯后，AI可行性就会自然融入写作，不需要额外检查。
