# 短剧剧本投稿审核技能

> 归属：茗舒

## 定位

投稿前的最后一道关。把剧本丢进来，按10个维度逐项检查，输出分级审核报告，标明必改项和建议项，确保投稿不被退回。

## 触发场景

用户说"审一下""审核""审稿""投稿前检查""帮我看看能不能过""查格式""过一遍"等。

## 审核前确认

在开始审核前，必须先确认：

1. **制作模式**：国内下沉剧 / 海外仿真人原创 / 海外AI剧本
2. **审核阶段**：一审材料 / 二审材料 / 全本剧本
3. **审核范围**：全部文件 / 指定集数

确认后读取对应文件，开始逐项检查。

## 十大审核维度

### 一、材料完整性 ✅/❌

**一审材料检查：**
- [ ] 故事梗概（500-800字完整故事）
- [ ] 人物小传（主要角色信息表）
- [ ] 一卡集纲（按3-5集分组概括全部集数）
- [ ] 压缩包命名是否正确（公司简称+日期+本数）

**二审材料检查：**
- [ ] 人设确认稿
- [ ] 故事梗概确认稿
- [ ] 大纲确认稿
- [ ] 分集细纲（每集列出场次、人物、事件、爽点、钩子）

### 二、格式合规 ✅/❌

**场景头：**
- [ ] 格式正确（海外：`集数-场次 地点 日/夜 内/外`）
- [ ] 每个场景都有场景头
- [ ] 内/外、日/夜标注无遗漏

**人物列表：**
- [ ] 每场都列出出场人物
- [ ] 格式为 `人物：角色A、角色B`

**动作描写：**
- [ ] 以 `△` 开头
- [ ] 每个动作独立成行
- [ ] 角色首次出场有外貌/服装描写

**台词格式：**
- [ ] `角色名（情绪/动作）：台词`
- [ ] VO标注正确：`角色名（VO）：内心独白`
- [ ] 括号内有情绪或动作标注

**字数规格：**
- [ ] 国内下沉剧：每集≥800字
- [ ] 海外仿真人：每集600-700字
- [ ] 海外AI：每集600-800字

### 三、题材合规 ✅/❌

根据制作模式检查是否踩到收稿禁区：

**国内下沉剧：**
- [ ] 不含东方玄幻（修仙/仙侠/玄幻升级流）

**海外仿真人原创：**
- [ ] 男频：不含脑洞向
- [ ] 女频：不含后悔流
- [ ] 女频：非纯暧昧向
- [ ] 甜宠/BL如有，标注"慎重，需确认"

**海外AI剧本：**
- [ ] 题材在收稿范围内

### 四、节奏检查 🟢/🟡/🔴

- [ ] **开场冲突**：第1集前3个动作行内是否有明确冲突/压迫
- [ ] **每集爽点**：每集是否有至少1-2个冲突升级或爽点
- [ ] **每集结尾钩子**：每集最后是否留了悬念让人想看下一集
- [ ] **情绪节奏**：是否存在连续2集以上同一情绪（虐虐虐/平平平）
- [ ] **付费卡点**：8-12集区间是否有强力钩子（免费转付费节点）
- [ ] **拖戏检测**：是否有整场戏没有推动剧情、纯填充

### 五、逻辑连贯性 🟢/🟡/🔴

- [ ] **情节矛盾**：前面说了A，后面变成B
- [ ] **角色行为逻辑**：行为是否符合人设（不突然降智/突然开挂）
- [ ] **因果链**：事件A是否自然导致事件B，还是强行跳转
- [ ] **伏笔回收**：埋下的线索后续是否有交代
- [ ] **时间线**：时间顺序是否通顺，不出现穿越bug
- [ ] **空间逻辑**：角色不能上一秒在A地下一秒在B地（除非有传送能力）

### 六、上下文衔接 🟢/🟡/🔴

- [ ] **集与集衔接**：上集结尾的悬念，下集是否接住
- [ ] **场与场衔接**：场景切换是否有逻辑过渡
- [ ] **角色状态延续**：上场受伤的，下场不能突然满血（除非交代）
- [ ] **信息传递**：角色A在场景1得知的信息，在后续场景中行为是否一致

### 七、人物一致性 🟢/🟡/🔴

- [ ] **角色名统一**：全文同一角色是否用同一个名字（不出现忽然换名/错名）
- [ ] **性格一贯**：性格是否保持一致（有变化必须有事件触发）
- [ ] **能力边界**：角色能力是否在设定范围内（不突然获得未交代的能力）
- [ ] **人物关系**：关系标签是否前后一致（不会上文叫哥下文叫叔）
- [ ] **人物消失**：已出场角色是否突然消失不再提及

### 八、台词自然度 🟢/🟡/🔴

**AI感检测（每条命中为🔴）：**
- [ ] 书面语/论文腔："因此""综上""值得注意的是""不得不说"
- [ ] AI万能句式："我理解你的感受""请你相信我""你要知道""事实上"
- [ ] 过度完整工整：真人不会说的完美长句
- [ ] 排比说教：三个以上并列的"要xxx，要xxx，要xxx"
- [ ] 无功能台词：不推动剧情、不揭示信息、不制造冲突的空话

**口语化检测（每条通过为🟢）：**
- [ ] 情绪激动时句子短碎（愤怒/崩溃不说长句）
- [ ] 有省略、有打断、有口语化表达
- [ ] 不同角色语言风格有辨识度（反派/主角/配角各有各的调）
- [ ] 台词符合角色身份和教育水平
- [ ] 符合角色当前情绪状态（不会哭着讲道理）

### 九、动作/画面可拍性 🟢/🟡/🔴

- [ ] **无心理描写**：不写"她心想""他感到"，只写镜头能拍到的动作
- [ ] **动作具体**：不写"攻击了她"，写"抬脚踹向残肢伤口"
- [ ] **情绪外化**：用身体反应替代情绪词（"爪尖掐破掌心"而非"她很愤怒"）
- [ ] **AI/漫可实现**：画面是否在AI仿真人或AI漫的制作能力范围内
- [ ] **无过度复杂场面**：不写几百人大场面/复杂特效（除非确认制作方支持）

### 十、AI生成痕迹（重点针对海外AI剧本）🟢/🟡/🔴

- [ ] **逻辑断裂**：前后文无关联的突然跳转
- [ ] **角色凭空消失/出现**：上一场还在的角色突然不见了
- [ ] **重复句式**：连续出现类似的句子结构
- [ ] **重复情节**：同样的冲突换个壳又来一遍
- [ ] **信息矛盾**：AI前面写了A设定，后面忘了变成B
- [ ] **莫名的东西**：不合逻辑、不合设定的诡异情节

## 输出格式

审核完成后，输出 `审核报告.md`，格式如下：

```markdown
# 审核报告

## 基本信息
- 项目名：XXX
- 制作模式：海外AI剧本
- 审核阶段：一审材料
- 审核日期：2026-XX-XX

## 审核结论：🟢通过 / 🟡有条件通过（需修改后重审）/ 🔴不通过

## 必改项（🔴）
1. [维度] 具体问题 → 修改建议
2. ...

## 建议项（🟡）
1. [维度] 具体问题 → 优化方向
2. ...

## 通过项（🟢）
- 格式合规 ✅
- 题材合规 ✅
- ...

## 逐集检查明细（如审核全本）

### 第1集
- 节奏：🟢 开场冲突明确
- 台词：🟡 第2场Helena台词偏书面
- 逻辑：🟢
- ...

### 第2集
...
```

## 快速审核模式

如果用户只是想快速过一遍而非完整审核，可以说"快速审一下"，此时只检查：
1. 格式是否正确
2. 每集是否有钩子
3. 明显的逻辑bug
4. 明显的AI味台词

输出精简报告，不做逐集明细。

## 审核流程

1. 确认制作模式 + 审核阶段
2. 读取所有相关文件
3. 按十大维度逐项检查
4. 输出审核报告（保存为 `审核报告.md`）
5. 如有必改项，引导用户修改后重新提交审核
