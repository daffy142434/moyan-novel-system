# 单集剧本示例

> 以下为都市爽文《龙王归来》第1集的完整剧本示例（短剧模式）。

---

```
剧名：《龙王归来》
集数：EP-01  三年期满
模式：短剧
对应剧情点：【剧情01】~【剧情03】
原著章节：第1章 ~ 第2章
情绪类型：🔨→❓（压力蓄积→悬念引爆）
情绪强度：8/10

════════════════════════════════════════

场次 01-1：内  破旧出租屋  夜
────────────────────────────────────────
出场人物：陈锋；林小雨

△ （全景）逼仄的出租屋，墙皮脱落，灯光昏黄。
  折叠桌上摆着两盘素菜和一个歪斜的小蛋糕。

△ （近景）陈锋坐在桌边，双手粗糙，指节有旧伤。
  他看着蛋糕，嘴角微微上扬。

陈锋
（温柔）
小雨，三年了，委屈你了。

△ （中景）林小雨端出一碗汤，围裙沾着油渍，
  脸上带着满足的笑。

林小雨
（笑着摇头）
不委屈。就是——

△ 她的笑容僵住，低头看手机。

林小雨
（慌张）
我妈又催了，明天家宴，你一定得到。

△ （特写）陈锋眼神瞬间变深，握筷的手微微收紧。

陈锋
（平静）
去。该见的人，总要见。

────────────────────────────────────────

场次 01-2：内  林家豪宅·客厅  日
────────────────────────────────────────
出场人物：陈锋；林小雨；林母；林浩天；赵倩

△ （全景）金碧辉煌的客厅，水晶灯，真皮沙发。
  陈锋穿着洗白的T恤站在门口，格格不入。

♪ 压抑的低频配乐

林母
（扫一眼陈锋，皱眉）
就带了这么个东西回来？

△ 全场哄笑。林小雨攥紧陈锋衣角。

林浩天
（翘腿，弹雪茄灰）
姐，这种废物趁早离了。赵家公子才配。

赵倩
（掩嘴笑）
浩天说得对，林家的门面可不能毁了。

△ 更多人加入嘲笑，声浪一波接一波。

林母
（拍桌）
陈锋，你自己说，配不配站在这？

△ （特写）陈锋一言不发。左手无名指的黑色戒指
  微微泛出暗光。

────────────────────────────────────────

场次 01-3：内  林家豪宅·客厅  日
────────────────────────────────────────
出场人物：陈锋；林小雨；林母；林浩天

☎ 突然，陈锋口袋里的手机震动。

△ （特写）屏幕上四个字：「龙主，时候到了。」

△ 全场安静了一秒——没人在意这条消息。
  嘲笑声继续。

△ （近景）陈锋缓缓抬头。嘴角勾起一丝冷笑。

陈锋
（声音很轻，但每个人都听清了）
三年期满。该还的，一分不少。

△ （特写）林浩天的笑容僵在脸上。
  林母端杯子的手停在半空。

※ 画面骤然降温，色调转冷。

════════════════════════════════════════

【卡黑】

下集预告：十二名黑衣人列队而至——当他们跪下的那一刻，
所有人都明白了，三年来他们羞辱的那个人，到底是谁。
```

---

## 示例要点解析

1. **开场用温馨反衬**：先展现底层生活的温情，与后面林家的羞辱形成强烈对比
2. **压力层层加码**：林母→林浩天→赵倩→全场，嘲笑力度逐步升级
3. **悬念引爆精准**：在压力最高点插入神秘来电，一句话翻转全局气场
4. **结尾卡黑时机**：停在观众最想知道「他到底是谁」的时刻
5. **字数控制**：约650字，符合短剧模式500-800字规格
6. **景别分布**：全景2次、中景1次、近景2次、特写4次，关键情绪点用特写
