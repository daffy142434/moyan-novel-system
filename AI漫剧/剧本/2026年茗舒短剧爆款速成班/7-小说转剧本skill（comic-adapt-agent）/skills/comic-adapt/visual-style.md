# 视觉化写作风格规范

## 一、总体风格定位

快节奏、强画面、重冲击。每一行文字都要能转化为一帧画面或一句可以说出口的台词。

---

## 二、场景描写规范

### 视觉描述符号系统

| 符号 | 含义 | 用法 |
|------|------|------|
| △ | 动作/场景描写 | △ （景别）具体描写内容 |
| ※ | 特殊视觉效果 | ※ 光效/特效/气氛渲染 |
| 【】 | 画外音/旁白/字幕 | 【旁白】内容 / 【字幕：三天后】 |
| （） | 语气/动作指示 | （冷笑）（猛地拍桌） |
| ♪ | 背景音乐提示 | ♪ 紧张悬疑配乐渐起 |
| ☎ | 电话/通讯 | ☎ 手机铃声响起 |

### 景别标注

| 景别 | 用途 |
|------|------|
| （全景） | 开场建立环境、群体场面 |
| （中景） | 两人对话、常规交互 |
| （近景） | 情感表达、重要对话 |
| （特写） | 情绪爆发、关键物件、面部表情 |
| （远景） | 气势场面、环境渲染 |

**短剧模式**：全集标注5-8处景别
**动态漫模式**：全集标注8-12处景别

### △ 描写铁律

1. 每段 △ 不超过3行（动态漫可放宽到4行）
2. 必须使用动态动词，禁止静态描述
3. 每段 △ 只描述一个动作或画面
4. 首次出现的场景需要环境描写，再次出现直接进台词

**正确示范**：
```
△ （特写）陈锋的手指缓缓收紧，将合同纸角压出折痕。
```

**错误示范**：
```
△ 陈锋坐在椅子上，桌子上有一份合同，房间里很安静，
  窗外是城市的夜景，他的心情很复杂，既有愤怒又有
  悲伤，还有一丝不甘……
```

---

## 三、台词写作规范

### 核心原则

台词不是把小说里的心理描写改成角色说出来的话。台词是：**这个人，在这个场景下，真的会开口说什么。**

### 角色语言分层

| 角色类型 | 说话特征 | 示例 |
|---------|---------|------|
| 大佬/强者 | 简短、命令式、不解释 | 「处理掉。」「我的人，谁动谁死。」 |
| 弱势角色 | 犹豫、解释多、反问 | 「我……我只是想说……」 |
| 反派嚣张 | 轻蔑、嘲讽、优越感 | 「就你？也配？」 |
| 市井角色 | 口头禅多、情绪外露 | 「我跟你说，这事儿没完！」 |
| 古代权贵 | 文雅有力、少现代词 | 「本王的事，轮不到你置喙。」 |

### 情绪烈度与台词密度

| 情绪烈度 | 台词长度 | 示例 |
|---------|---------|------|
| 极度愤怒/震惊 | 1-5字 | 「滚。」「你——」 |
| 强烈对抗 | 5-15字 | 「你有几条命，再说一遍试试。」 |
| 日常对话 | 15-25字 | 「这件事我来处理，你不用管。」 |
| 信息铺垫 | 20-30字 | 「三年前那份合同，是你父亲亲手签的。」 |

### 台词三行结构（强制）

```
角色名
（语气/动作指示）
台词正文。
```

### 五类禁忌台词

| 类型 | 错误示例 | 修正方向 |
|------|---------|---------|
| 自我剖析式 | 「我知道自己很脆弱，但我不能倒下。」 | 改为动作：△ 他咬牙，重新站直。 |
| 旁白解说式 | 「你以为你赢了，其实你已经输了。」 | 必须有具体所指，不能悬空 |
| 文学抒情式 | 「爱情如同一把双刃剑。」 | 删除，改为具体事件 |
| 过度礼貌式 | 「非常感谢您的帮助，铭记于心。」 | 「这份情，我记着。」 |
| 信息过载式 | 一句话塞入时间地点人物原因 | 拆成2-3句或改为 △ |

## 四、信息呈现转化规则

### 心理活动→外部呈现

| 转化方式 | 优先级 | 适用场景 |
|---------|-------|---------|
| 动作化 | 首选 | 用表情和肢体语言表达内心 |
| 台词化 | 次选 | 心理有明确指向时，说出克制的话 |
| 直接删除 | 兜底 | 过渡性心理活动 |

### 背景信息呈现

- **少量信息**：融入角色对话（「陈家？那个三年前破产的陈家？」）
- **时间地点**：字幕标注（【字幕：三天后 / 上海】）
- **世界观设定**：用角色反应带出（「他直接跨越了筑基期？！」）

---

## 五、每集结构模板

### 短剧模式

| 位置 | 占比 | 要求 |
|------|------|------|
| 开场 | 前2行 | 引爆冲突，承接上集钩子 |
| 发展 | 中间60% | 冲突升级，至少1次反转 |
| 高潮 | 25% | 爽点释放或情绪顶峰 |
| 钩子 | 最后1-2行 | 强悬念，让人想看下集 |

### 动态漫模式

| 位置 | 占比 | 要求 |
|------|------|------|
| 开场 | 前4行 | 建立冲突，稍有铺垫空间 |
| 发展 | 中间55% | 冲突发展，可有情感对白 |
| 高潮 | 25% | 爽点释放，情绪更完整 |
| 钩子 | 最后2-3行 | 悬念或情感余韵 |

---

## 六、每集结尾固定格式

```
【卡黑】

下集预告：[一句话悬念钩子]
```

**【卡黑】是漫剧剧本的标准结尾标记，表示画面转黑，本集结束。**

---

## 七、场景重复处理

- **首次出现**：完整场景头 + △ 环境描写
- **再次出现**：只写场景头，直接进台词
- **场景发生变化时**：重新写 △，突出变化
