# 全题材大纲创作方法论

## 总体取向

短篇小说重"**冲突张力**"与"**情节完整性**",以紧凑的结构和鲜明的人物为核心。

**核心原则**:
- 聚焦核心矛盾(情感冲突、权力斗争、谜题解密、成长突破等)
- 追求"可共情":让读者投入角色的处境和选择
- 兼顾爽点与逻辑性,但**不脱离题材设定**
- 以关键节点反转推动情节,**符合题材逻辑和因果关系**

---

## 整体创作公式
```
短篇小说 = 明确的目标 + 强烈的阻碍 + 艰难的抉择 + 有代价的结局
```

---

## 一、核心梗概写作

### 公式
```
核心梗概 = 人物标签 + 核心困境 + 核心冲突
```

### 写作要点
| 要素 | 要求 | 正确示例 | 错误示例 |
|------|------|---------|---------|
| **人物标签** | 身份+特征+处境 | "刚入宫的选秀女""失忆的侦探""被退婚的废柴少爷" | "一个人""主角" |
| **核心困境** | 具体的困境或目标 | "必须在三日内查清真凶""要在一个月内修炼到筑基期" | "遇到了麻烦" |
| **核心冲突** | 两难选择或对抗 | "在爱情和家族之间""与掌握真相的仇人联手""牺牲队友还是放弃任务" | "面临选择" |

### 优秀示例(不同题材)

**现代言情**:
- "暗恋七年的她成了我的顶头上司,一份合同让我必须在爱情和事业之间做出选择"
- "离婚协议签完的第二天,前夫查出绝症,我该不该回去照顾他"

**古代权谋**:
- "新帝登基第三日,我这位拥兵的藩王必须在三天内交出兵权,交则死,不交则反"
- "太后密旨让我除掉皇帝,但皇帝恰是我暗中扶持多年的少年"

**悬疑推理**:
- "连环杀人案的所有证据都指向我死去的哥哥,我必须在警方封锁真相前找出真凶"
- "密室里的尸体是我的初恋,而我是唯一拥有钥匙的人"

**奇幻玄幻**:
- "宗门大比在即,我这个吊车尾必须在一个月内突破境界,但唯一的办法是与心魔交易"
- "成为天选之子的代价是吞噬队友的灵力,我是英雄还是恶魔"

## 二、导语写作

### 公式
```
导语 = 爆点事件 + 题材特色细节 + 悬念钩子
```

### 写作要点
| 要素 | 作用 | 写法 |
|------|------|------|
| **第一句** | 开门见山抛冲突 | 直接写事件,不铺垫 |
| **中间部分** | 增强题材代入感 | 用题材特色元素(宫廷术语/破案线索/修炼境界/商战细节) |
| **最后一句** | 制造悬念 | 留下关键问题或倒计时 |

### 不同题材的导语要点

| 题材类型 | 核心元素 | 示例关键词 |
|---------|---------|---------|
| **现代言情** | 情感张力、现实阻碍 | 前任/误会/身份差距/家族反对/暗恋/离婚/重逢 |
| **古代权谋** | 权力格局、生死博弈 | 圣旨/密谋/兵权/朝堂/党争/血脉/玉玺/诏书 |
| **悬疑推理** | 谜题线索、真相悬念 | 密室/尸体/证据/嫌疑人/不在场证明/动机/凶器 |
| **都市职场** | 职场困境、利益冲突 | 裁员/竞争/项目/升职/背叛/商业机密/合同 |
| **奇幻玄幻** | 世界观、力量体系 | 境界/灵力/宗门/天赋/血脉/试炼/秘境/丹药 |
| **科幻未来** | 科技设定、人性冲突 | AI/星际/时空/基因/机械/意识上传/末日/虫洞 |

### 示例对比
| 题材 | 正确示例 | 错误示例 |
|------|---------|---------|
| **现代言情** | "订婚宴上,他当着所有人的面说他爱的是我姐姐。三个月后,姐姐出车祸成了植物人,他跪在我面前说'替她嫁给我'。" | "这是一个关于爱情的故事,女主角面临艰难抉择..." |
| **古代权谋** | "登基大典的前夜,太后寝宫传出一道密旨——除掉新帝。而我,这位手握禁军的大将军,必须在天明前做出选择。顺从,则弑君;抗命,则灭族。" | "皇宫里发生了一些事情,主角陷入了困境..." |
| **悬疑推理** | "密室里躺着三具尸体,死亡时间相差不到五分钟。监控显示只有我一个人进出过。72小时后,如果找不到真凶,我将以连环杀人罪被起诉。" | "发生了一起神秘的案件,侦探开始调查..." |

## 三、起承转合结构设计

### 【起】第1章:诱因与困境(2000-3000字)

#### 写作重点
```
起 = 快速入局 + 建立核心矛盾 + 困境具象化 + 钩子
```

| 模块 | 写作要点 | 不同题材的具体方法 |
|------|---------|-------------------|
| **快速入局** | 开场即冲突 | **现代言情**:表白/拒绝/重逢/误会<br>**古代权谋**:密旨/兵变/毒杀/夺嫡<br>**悬疑推理**:案发/报警/发现尸体/接到威胁<br>**奇幻玄幻**:遇袭/突破失败/被逐出师门/天赋觉醒 |
| **建立核心矛盾** | 明确目标与阻碍 | **现代言情**:想在一起但有现实阻碍(身份/家族/误会)<br>**古代权谋**:想保命/夺权但对手太强/时间太紧<br>**悬疑推理**:想查清真相但证据指向自己/线索被毁<br>**奇幻玄幻**:想变强但天赋低/时间紧/代价大 |
| **困境具象化** | 用细节呈现压力 | **现代言情**:倒计时(三天后婚礼/一周后出国)/具体障碍(父母反对/前任纠缠)<br>**古代权谋**:时间限制(三日交出兵权)/阵营对峙(太后派vs皇帝派)<br>**悬疑推理**:物证(指纹/血迹/凶器)/时间压力(72小时拘留期)<br>**奇幻玄幻**:境界差距(筑基期vs金丹期)/资源短缺(灵石不足/丹药耗尽) |
| **章末钩子** | 具体事件推动 | 一个决定/一条信息/一次相遇/一场意外 |

#### 禁忌
- ❌ 过长的背景铺垫
- ❌ 大段环境描写
- ❌ 缓慢的日常展开

---

### 【承】第2-3章:推进与加压(每章2000-3000字)

#### 第2章写作重点
```
第2章 = 主动行动 + 小成果 + 新问题 + 压力升级
```

| 模块 | 写作要点 | 不同题材的具体方法 |
|------|---------|-------------------|
| **主动行动** | 角色采取行动 | **现代言情**:表白/澄清误会/调查真相/接近对方<br>**古代权谋**:拉拢盟友/设局试探/调查对手/布置后手<br>**悬疑推理**:调查现场/询问证人/分析线索/追踪嫌疑人<br>**奇幻玄幻**:寻找机缘/闭关修炼/挑战对手/探索秘境 |
| **小成果+新问题** | 表面进展,实则更难 | **现代言情**:解开误会→发现新的隐瞒/接近成功→出现新的竞争者<br>**古代权谋**:拉到盟友→盟友另有所图/除掉对手→对手留了后手<br>**悬疑推理**:找到线索→线索指向更大的阴谋/锁定嫌疑人→嫌疑人有不在场证明<br>**奇幻玄幻**:突破境界→引来强敌/获得宝物→宝物有副作用 |
| **关系线展开** | 引入配角 | 展现不同立场,制造关系张力 |
| **压力升级** | 时间更紧/赌注更大 | 根据题材设定升级对应的压力源 |

#### 第3章写作重点
```
第3章 = 第二次受阻 + 核心冲突爆发 + 关系撕裂 + 引向转折
```

| 模块 | 写作要点 | 不同题材的具体方法 |
|------|---------|-------------------|
| **第二次受阻** | 计划失败/遇到瓶颈 | **现代言情**:被拒绝/误会加深/第三者插足/家族施压<br>**古代权谋**:盟友背叛/阴谋败露/陷入绝境/敌人反扑<br>**悬疑推理**:关键证人死亡/证据被毁/陷入圈套/凶手留下新线索<br>**奇幻玄幻**:修炼走火入魔/挑战失败/资源耗尽/遭遇暗算 |
| **核心冲突爆发** | 两难选择具象化 | **现代言情**:在爱情和其他(事业/家人/自尊)之间<br>**古代权谋**:在忠诚和生存/正义和权势之间<br>**悬疑推理**:在真相和保护某人之间<br>**奇幻玄幻**:在力量和代价(人性/队友/师门)之间 |
| **关系撕裂** | 配角与主角冲突 | 一次争吵/决裂/背叛/对立 |
| **引向转折** | 关键信息出现 | **现代言情**:发现真相/意外重逢/第三方揭秘<br>**古代权谋**:密信/遗物/叛徒供词/藏宝图<br>**悬疑推理**:新证据/证人出现/凶手留下破绽<br>**奇幻玄幻**:秘籍/传承/前辈指点/血脉觉醒 |

---

### 【转】第4章:关键抉择(2000-3000字)

#### 写作重点
```
转 = 局势逆转 + 压力峰值 + 关键决定 + 行动具体化
```

| 模块 | 写作要点 | 不同题材的具体方法 |
|------|---------|-------------------|
| **局势逆转** | 基于前文伏笔 | **现代言情**:真相大白/身份揭晓/误会解除/态度转变<br>**古代权谋**:证据翻盘/盟友归位/诏书到/底牌亮出<br>**悬疑推理**:真凶暴露/动机揭示/密室真相/证据链还原<br>**奇幻玄幻**:境界突破/宝物认主/绝技领悟/血脉觉醒 |
| **压力峰值** | 全篇最大冲突 | **现代言情**:最后的告白/订婚现场/机场送别/生死关头<br>**古代权谋**:朝堂对质/御前辩论/兵临城下/生死一线<br>**悬疑推理**:与凶手对峙/真相公开/生死时刻<br>**奇幻玄幻**:生死对决/突破劫难/最终试炼 |
| **关键决定** | 做出选择 | 符合人物性格和前文铺垫,不是突然的转变 |
| **行动具体化** | 用动作不用宣言 | ✅ "他跪下了/签了字/拔出剑/握住她的手"<br>❌ "他决定了/他明白了/他想通了" |

#### 禁忌
- ❌ 用巧合翻盘(天降贵人/突然的好运/不合理的力量暴增)
- ❌ 突然的人设崩塌
- ❌ 空洞的内心独白
- ❌ **悬空设定**:用超出题材逻辑的元素解决困境

---

### 【合】第5章:收束与余味(2000-3000字)

#### 写作重点
```
合 = 后果呈现 + 代价不回避 + 关系新平衡 + 留白照应
```

| 模块 | 写作要点 | 不同题材的具体方法 |
|------|---------|-------------------|
| **后果呈现** | 不回避代价 | **现代言情**:在一起→失去其他/选择事业→错过爱情/和解→伤痕犹在<br>**古代权谋**:赢得权力→失去盟友/保住性命→失去地位/守住忠义→家族覆灭<br>**悬疑推理**:找到真凶→真相让人心碎/保护某人→背负罪名<br>**奇幻玄幻**:突破成功→付出代价/打败对手→身负重伤/获得力量→失去人性 |
| **关系新平衡** | 配角的结局 | 用一次对话或行动收束,避免全员大团圆 |
| **题材特色收尾** | 符合类型特征 | **现代言情**:甜蜜日常/意味深长的对视/开放式结局<br>**古代权谋**:新的权力格局/埋下新的隐患/历史评价<br>**悬疑推理**:真相揭晓/正义伸张/留下新的疑问<br>**奇幻玄幻**:境界稳固/展望未来/埋下新的冒险伏笔 |
| **留白照应** | 用第1章元素 | 同样的场景/物件/台词,但情境已变 |

#### 禁忌
- ❌ 假团圆(所有矛盾都完美解决)
- ❌ 过度解释
- ❌ 说教式总结
- ❌ 与题材调性不符的结局(如悲剧题材强行Happy Ending)

## 四、人物塑造方法

### 主角设计

#### 通用维度
| 维度 | 要求 | 不同题材示例 |
|------|------|------------|
| **身份标签** | 具体+有特点 | **现代言情**:"海归投资经理"<br>**古代权谋**:"失宠的七皇子"<br>**悬疑推理**:"退休刑警"<br>**奇幻玄幻**:"被退婚的废柴少爷" |
| **核心特质** | 2-3个鲜明特点 | 理性冷静/偏执多疑/心思缜密/重情重义 |
| **起始困境** | 具体的处境 | 根据题材设定对应的困境 |
| **行动逻辑** | 符合身份的行为模式 | 专业人士用专业方法/江湖人用江湖规矩 |

#### 题材特色设计

**现代言情主角**:
- 职业真实可信(投行/医生/律师/设计师)
- 情感创伤或恋爱观(被伤害过/不信任爱情/家庭影响)
- 外在形象(穿着品味/气质特征)
- 恋爱模式(主动/被动/欲拒还迎)

**古代权谋主角**:
- 明确的政治立场(太子党/藩王派/清流/外戚)
- 手中的资源(兵权/财权/情报/盟友)
- 权谋手段(正面对抗/暗中布局/以退为进)
- 底线和软肋(家人/师恩/忠义/理想)

**悬疑推理主角**:
- 观察能力或推理方式(细节控/逻辑推理/心理分析)
- 与案件的关系(受害者/调查者/嫌疑人/知情者)
- 性格缺陷(偏执/自负/创伤/恐惧)
- 推理的盲点(情感/偏见/过去)

**奇幻玄幻主角**:
- 天赋设定(废柴逆袭/天才/特殊体质/隐藏血脉)
- 修炼体系(当前境界/修炼速度/特殊功法)
- 成长目标(复仇/变强/守护/证明自己)
- 金手指限制(有代价/有条件/成长型)

### 压力具象化

不同题材的压力表现:

| 题材 | 压力类型 | 具体化方法 |
|------|---------|----------|
| **现代言情** | 时间/身份/误会/第三者 | "三天后他就订婚了""总裁vs秘书的身份差距""那封被误读的邮件" |
| **古代权谋** | 时限/阵营/生死/忠诚 | "七日内交兵权""太后党vs皇帝党""全族性命""君臣vs兄弟情" |
| **悬疑推理** | 证据/时间/嫌疑/真相 | "72小时拘留期""指纹在凶器上""所有人都有动机""真相会毁掉某人" |
| **奇幻玄幻** | 境界/资源/时间/代价 | "筑基期vs金丹期的差距""灵石只剩三颗""宗门大比只有一月""突破需要牺牲队友" |

### 配角设计(2-4个功能性配角)

| 类型 | 作用 | 不同题材示例 |
|------|------|------------|
| **对手** | 制造冲突 | **现代言情**:情敌/前任<br>**古代权谋**:政敌/竞争者<br>**悬疑推理**:凶手/同行<br>**奇幻玄幻**:同门对手/仇家 |
| **助力** | 协助主角 | **现代言情**:闺蜜/暖男二号<br>**古代权谋**:谋士/死士<br>**悬疑推理**:搭档/证人<br>**奇幻玄幻**:队友/师父 |
| **催化剂** | 推动剧情 | 制造误会/揭露真相/提供关键信息 |
| **对照组** | 反衬主角 | 不同的选择路径/失败的案例/另一种可能 |

## 五、爽点设计(全题材通用)

### 爽点公式
```
爽点 = 困境逆转 + 符合逻辑 + 情感满足
```

### 不同题材的爽点类型

#### 现代言情爽点
| 类型 | 方法 | 示例 |
|------|------|------|
| **身份反差爽** | 灰姑娘vs王子,实际地位反转 | "以为是穷小子,其实是总裁" |
| **误会解除爽** | 真相大白,误会消除 | "原来那晚他是去救我" |
| **吃醋争风爽** | 吃醋/宣示主权/护短 | "他当众说'她是我的人'" |
| **虐后甜爽** | 受尽委屈后,对方追悔莫及 | "分手后他发现离不开她" |

#### 古代权谋爽点
| 类型 | 方法 | 示例 |
|------|------|------|
| **计谋取胜爽** | 以弱胜强,用智慧翻盘 | "将计就计反将一军" |
| **真相反转爽** | 被冤枉多年,证据翻案 | "密信证明清白" |
| **身份揭秘爽** | 隐藏身份暴露,众人惊讶 | "废柴皇子原是隐忍高手" |
| **忠义两全爽** | 既保住忠义又活下来 | "找到两全其美的方法" |

#### 悬疑推理爽点
| 类型 | 方法 | 示例 |
|------|------|------|
| **真相大白爽** | 谜题解开,逻辑自洽 | "所有线索串起来" |
| **凶手暴露爽** | 完美伪装被识破 | "一个细节出卖了凶手" |
| **智商碾压爽** | 推理能力压制对手 | "侦探一步步拆穿谎言" |
| **正义伸张爽** | 冤案昭雪,恶人伏法 | "真凶被抓,无辜者清白" |

#### 奇幻玄幻爽点
| 类型 | 方法 | 示例 |
|------|------|------|
| **境界突破爽** | 关键时刻升级 | "战斗中悟道突破" |
| **碾压反击爽** | 曾经被欺负,现在一招秒杀 | "三年前你羞辱我,今日我已金丹" |
| **宝物认主爽** | 神器/功法选中主角 | "只有他能驾驭的上古神剑" |
| **身份揭秘爽** | 废柴原是天才/隐藏血脉觉醒 | "原来我是古族后裔" |

### 设计原则
- ✅ 爽点建立在**题材逻辑**之上
- ✅ 依靠**前文铺垫和合理因果**
- ✅ 即使是爽点,也要有**适当代价**
- ❌ 不用超出题材设定的力量(现代言情不用玄幻金手指,古代权谋不用现代科技)

## 六、冲突设计

### 冲突公式
```
冲突 = 外部压力(可量化/可观察) + 内部困境(两难选择) + 递进层次
```

### 不同题材的外部冲突

| 题材 | 压力类型 | 具体化方法 |
|------|---------|----------|
| **现代言情** | 时间/身份/第三者/家族 | 倒计时/身份差距/前任出现/父母反对 |
| **古代权谋** | 时限/阵营/生死/势力 | 限期交权/党派斗争/满门抄斩/兵力悬殊 |
| **悬疑推理** | 证据/时间/嫌疑/真相 | 不利证据/拘留期限/所有人有嫌疑/真相代价 |
| **奇幻玄幻** | 境界/资源/时间/对手 | 等级压制/灵石不足/大比在即/强敌环伺 |

### 内部冲突(通用)

| 冲突类型 | 设计方法 | 各题材示例 |
|---------|---------|----------|
| **价值观冲突** | "对vs对"的选择 | **现代**:爱情vs事业<br>**权谋**:忠义vs生存<br>**推理**:真相vs保护<br>**玄幻**:力量vs人性 |
| **关系冲突** | 重要关系的撕裂 | 爱人/师父/兄弟/队友之间的矛盾 |
| **自我认知冲突** | 我是谁/我要什么 | 身份认同/价值怀疑/信念动摇 |

## 七、伏笔管理

### 伏笔载体(不同题材)

| 题材 | 载体类型 | 示例 |
|------|---------|------|
| **现代言情** | 物件/信息/过往 | 项链/照片/日记/误发的消息/过去的约定 |
| **古代权谋** | 文书/证物/证人 | 密信/玉佩/血书/遗诏/旧部/暗桩 |
| **悬疑推理** | 证据/记录/证言 | 指纹/监控/通话记录/目击者/遗留物 |
| **奇幻玄幻** | 功法/血脉/预言 | 残缺秘籍/封印记忆/前世因果/师门遗物 |

### 伏笔设置原则

| 阶段 | 方法 | 示例 |
|------|------|------|
| **埋设** | 轻描淡写,1-2句带过 | "他摸了摸胸口的玉佩""监控录像里有个模糊的身影""那封信她始终没看" |
| **回收** | 多线索汇聚 | **现代言情**:照片上的细节/对话中的破绽<br>**古代权谋**:多个证人/文书对质<br>**悬疑推理**:证据链还原/时间线对比<br>**奇幻玄幻**:回忆闪现/血脉共鸣 |
| **时机** | 在"转"的部分集中回收 | 真相大白/误会解除/身份揭秘/逆转翻盘 |

## 八、不同题材的特别注意事项

### 现代言情
- ✅ 情感合理性:误会、阻碍、和解都要有充分理由
- ✅ 人物成长:不只是在一起,还要情感上的成熟
- ❌ 避免:纯粹靠误会拖剧情/人物行为不符合现代人逻辑

### 古代权谋
- ✅ 历史感:称呼、礼仪、官职、制度要基本符合古代逻辑
- ✅ 权力结构:交代清楚势力分布、利益关系
- ❌ 避免:现代思维/女性角色过于现代化/历史大错

### 悬疑推理
- ✅ 逻辑自洽:所有线索能串起来,凶手动机合理
- ✅ 公平游戏:关键线索要在文中给出,不能突然冒出证据
- ❌ 避免:逻辑漏洞/强行巧合/凶手动机太弱

### 奇幻玄幻
- ✅ 体系清晰:修炼境界、力量等级、世界规则要明确
- ✅ 战斗逻辑:不只是比境界,要体现战斗智慧
- ❌ 避免:力量体系混乱/战力忽高忽低/主角无敌无脑爽

## 九、质量自检清单

创作完大纲后,用以下清单检验:

**结构完整性**:
- [ ] 起承转合结构完整,5章布局合理
- [ ] 每章都有明确的剧情推进
- [ ] 第4章的转折基于前文伏笔,不是突然的

**人物塑造**:
- [ ] 主角人设鲜明,符合题材特征
- [ ] 配角有功能性,不是工具人
- [ ] 人物行动逻辑一致,符合身份和性格

**冲突设计**:
- [ ] 外部压力明确且递进
- [ ] 内部冲突有两难选择
- [ ] 冲突符合题材逻辑,不悬空

**题材适配**:
- [ ] 世界观/背景设定符合题材特征
- [ ] 情节发展符合该题材的节奏
- [ ] 爽点设计符合该题材读者期待

**细节质量**:
- [ ] 有足够的题材特色细节(行话/物件/场景)
- [ ] 伏笔埋设自然,回收合理
- [ ] 结局有余味,符合题材调性
