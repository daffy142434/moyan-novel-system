# 全题材小说创作 Skill

> 归属：茗舒

[技能说明]
    专业的全题材短篇小说创作技能包,覆盖故事构思、人物塑造、章节规划、正文写作全流程。根据不同创作阶段,读取对应的创作资源并生成符合所选题材规范的小说内容。支持现代言情、古代权谋、悬疑推理、都市职场、奇幻玄幻、科幻未来等多种题材。

[文件结构]
    .claude/skills/short-novel-skill/
    ├── SKILL.md                        # 本文件(技能包核心配置)
    ├── outline-method.md               # 大纲创作方法论(含人物塑造指导)
    ├── output-style.md                # 写作风格(含章节创作方法)
    ├── examples/
    │   ├── outline-example.md          # 大纲示例
    │   ├── character-example.md        # 人物示例
    │   └── chapter-example.md          # 章节示例
    └── templates/                      # 文档结构模板(通用)
        ├── outline-template.md         # 大纲文档格式模板
        ├── character-template.md       # 人物小传格式模板
        ├── chapter-index-template.md   # 章节目录格式模板
        └── chapter-template.md         # 章节正文格式模板

[核心能力]
    - **创作阶段理解**:识别当前处于大纲、人物、目录还是章节创作阶段
    - **题材识别**:根据用户需求确定小说题材类型,应用对应的创作规则
    - **资源整合**:读取模板、方法论、风格、示例等多维度资源
    - **专业创作**:基于资源和上下文创作符合所选题材规范的小说内容
    - **风格把控**:确保创作内容符合所选题材的典型风格特征
    - **模板遵循**:严格按照模板格式生成文档结构
    - **上下文理解**:理解已有文档内容,确保创作连贯性

[支持的题材类型]
    - **现代言情**:都市爱情、职场恋爱、甜宠虐恋、破镜重圆
    - **古代权谋**:宫廷斗争、朝堂谋略、家族兴衰、王朝更替
    - **悬疑推理**:密室杀人、连环案件、心理悬疑、社会派推理
    - **都市职场**:职场困境、创业奋斗、行业竞争、人性考验
    - **奇幻玄幻**:修仙升级、异世冒险、魔法体系、天赋觉醒
    - **科幻未来**:星际探索、AI觉醒、时空穿越、末日求生
    - **武侠江湖**:武林纷争、侠义恩仇、门派斗争、江湖传说
    - **历史架空**:架空历史、穿越重生、改变历史、王朝兴衰

[执行流程]
    第一步:理解创作需求
        识别当前创作阶段:
        - 如果在讨论故事大纲或outline.md不存在 → 大纲创作阶段
        - 如果在讨论人物或刚执行/character → 人物创作阶段
        - 如果在讨论章节规划或刚执行/catalog → 目录创作阶段
        - 如果在创作章节正文或刚执行/write → 章节创作阶段
        
        识别小说题材:
        - 根据用户明确说明的题材(如"我要写古代权谋")
        - 根据故事设定推断题材(如"皇宫""朝堂"→古代权谋)
        - 如果不明确,询问用户确认题材类型

    第二步:读取创作资源
        **大纲创作阶段**:
            1. 读取 templates/outline-template.md(文档格式模板)
            2. 读取 outline-method.md(通用大纲创作方法论,含人物塑造指导)
            3. 读取 output-style.md(通用写作风格)
            4. 读取 examples/outline-example.md(大纲示例)
            5. 从对话历史获取用户回答的Q1-Q3(核心创意、核心冲突、故事调性)
            6. 根据题材类型应用对应的创作规则
        
        **人物创作阶段**:
            1. 读取 outline.md(了解故事背景和设定)
            2. 读取 templates/character-template.md(文档格式模板)
            3. 读取 outline-method.md(人物塑造指导部分)
            4. 读取 output-style.md(写作风格)
            5. 读取 examples/character-example.md(人物示例)
            6. 根据题材类型设计符合时代背景的人物
        
        **目录创作阶段**:
            1. 读取 outline.md 和 character.md(了解故事和人物)
            2. 读取 templates/chapter-index-template.md(文档格式模板)
            3. 读取 outline-method.md(章节规划方法)
            4. 读取 output-style.md(写作风格)
            5. 根据题材类型规划符合类型特征的情节节奏
        
        **章节创作阶段**:
            1. 读取 outline.md、character.md、chapter_index.md(全部上下文)
            2. 读取 templates/chapter-template.md(文档格式模板)
            3. 读取 output-style.md(写作风格和章节创作方法,最重要)
            4. 读取 examples/chapter-example.md(章节示例)
            5. 从chapter_index.md获取当前章节的规划内容
            6. 根据题材类型应用对应的场景描写和对话风格

    第三步:执行专业创作
        **大纲创作**:
            基于用户提供的信息(核心创意、核心冲突、故事调性)和读取的资源:
            - 严格按照 templates/outline-template.md 的格式结构
            - 遵循 outline-method.md 的通用创作方法论
            - 应用 output-style.md 的写作风格
            - 参考 examples/outline-example.md 的示例
            - 根据题材类型应用对应的设定规则:
                • 现代言情:情感线为主,设置误会、阻碍、甜虐情节
                • 古代权谋:权力斗争为主,设置阵营、利益、谋略博弈
                •悬疑推理:谜题为主,设置线索、红鲱鱼、真相揭示
                • 奇幻玄幻:世界观为主,设置体系、等级、修炼路线
                • 其他题材:根据类型特征设置对应的核心要素
            - 生成包含以下内容的完整大纲:
                • 小说信息(书名、题材类型、故事调性)
                • 核心梗概(一句话)
                • 导语(150-200字,包含题材特色元素)
                • 故事大纲(采用起承转合结构,2000-3000字)
                • 主要人物(简要列出3-5个核心人物)
        
        **人物创作**:
            基于outline.md的故事设定和读取的资源:
            - 严格按照 templates/character-template.md 的格式结构
            - 遵循 outline-method.md 中的人物塑造指导
            - 应用 output-style.md 的写作风格
            - 参考 examples/character-example.md 的示例
            - 根据题材类型设计人物:
                • 现代言情:注重情感特质、职业背景、恋爱观念
                • 古代权谋:注重身份地位、政治立场、权谋手段
                • 悬疑推理:注重动机隐藏、行为线索、真实面目
                • 奇幻玄幻:注重天赋设定、修炼体系、成长路线
                • 其他题材:根据类型特征设计对应的人物维度
            - 生成包含以下内容的人物小传:
                • 主要角色(3-5个,详细描述,符合题材特征)
                • 重要配角(如有)
                • 其他角色(如有)
            - 确保人物与故事冲突匹配,人物关系合理,符合题材逻辑
        
        **目录创作**:
            基于outline.md和character.md的设定和读取的资源:
            - 严格按照 templates/chapter-index-template.md 的格式结构
            - 遵循 outline-method.md 的章节规划方法
            - 应用 output-style.md 的写作风格
            - 根据题材类型规划章节节奏:
                • 现代言情:情感递进,误会→接近→冲突→和解
                • 古代权谋:权力博弈,布局→试探→交锋→定局
                • 悬疑推理:谜题展开,案发→调查→线索→真相
                • 奇幻玄幻:升级节奏,获得→修炼→突破→对决
                • 其他题材:根据类型特征安排对应的情节节奏
            - 生成固定5章的章节目录,与大纲的起承转合结构对应
            - 每章包含:章节标题 + 一句话剧情简介(体现题材特色)
            - 确保起承转合布局合理,节奏控制得当
        
        **章节创作**:
            基于全部上下文文档和读取的资源:
            - 严格按照 templates/chapter-template.md 的格式结构
            - 严格遵循 output-style.md 的写作风格和章节创作方法(最重要)
            - 参考 examples/chapter-example.md 的示例
            - 基于 chapter_index.md 中该章节的规划进行创作
            - 根据题材类型应用对应的写作技巧:
                • 现代言情:注重心理描写、对话张力、情感细节
                • 古代权谋:注重环境渲染、暗线铺设、对话机锋
                • 悬疑推理:注重线索埋设、气氛营造、节奏控制
                • 奇幻玄幻:注重战斗场景、能力展示、境界提升
                • 其他题材:根据类型特征应用对应的场景技巧
            - 生成2000-3000字的章节正文
            - 确保人物行为一致,剧情推进连贯

    第四步:返回创作成果
        **大纲创作阶段**:
            返回符合templates/outline-template.md格式的完整大纲内容
        
        **人物创作阶段**:
            返回符合templates/character-template.md格式的完整人物小传
        
        **目录创作阶段**:
            返回符合templates/chapter-index-template.md格式的完整章节目录
        
        **章节创作阶段**:
            返回符合templates/chapter-template.md格式的完整章节正文

[创作原则]
    - **模板遵循原则**:
        • 创作的所有文档必须严格遵循templates/中定义的格式
        • 不能遗漏模板中的必要标题和段落
        • 不能改变模板定义的层级结构
        • 可以根据实际需要调整内容的详略

    - **题材适配原则**:
        • 根据选定的题材类型应用对应的创作规则
        • 确保世界观、人物设定、情节发展符合题材逻辑
        • 使用符合题材特征的语言风格和叙事节奏
        • 融入题材典型元素,但避免刻板套路

    - **风格一致性原则**:
        • 所有创作必须保持同一题材的风格统一
        • 严格遵循output-style.md中定义的写作风格
        • 参考examples/中的示例风格
        • 确保大纲、人物、章节的风格协调

    - **上下文连贯性原则**:
        • character创作必须基于outline
        • catalog创作必须基于outline + character
        • chapter创作必须基于outline + character + catalog
        • 确保前后内容不矛盾,逻辑连贯

    - **质量标准原则**:
        • 大纲:核心冲突清晰,故事结构完整,固定起承转合结构,2000-3000字
        • 人物:性格鲜明,符合题材设定,与故事匹配
        • 目录:固定5章,与大纲的起承转合结构对应,布局合理
        • 章节:2000-3000字,风格统一,推进剧情,符合题材特征

[注意事项]
    - 确保每个阶段的必需资源都已读取完整
    - 不仅读取文档内容,还要深入理解其含义
    - output-style.md中的写作风格要求是强约束,必须严格遵守
    - templates/中的格式是必须遵循的,任何偏离都可能导致问题
    - 短篇小说固定为5章结构,采用起承转合布局
    - 不同题材有不同的创作重点,需要灵活应用
    - 创作内容必须完整、连贯、符合所选题材特点
    - 始终使用中文创作
