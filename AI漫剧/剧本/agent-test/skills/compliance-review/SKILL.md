# 合规审核技能

## 用途

由视觉指导在各阶段审核时调用，对提示词进行合规性检查，避免触发平台内容安全机制。

## 审核清单

### 一、真人肖像限制
- R01 高风险：不得生成真实公众人物肖像
- R02 高风险：提示词中不得出现真实人物姓名
- R03 中风险：避免特征组合导致与真实人物高度相似
- R04 中风险：不得生成证件照风格内容

### 二、版权IP限制
- C01 高风险：不得生成已有影视作品角色形象
- C02 高风险：不得生成已有动漫游戏角色
- C03 中风险：不得出现真实品牌logo商标
- C04 低风险：部分版权保护的标志性建筑需注意
- C05 中风险：不得指定模仿在世艺术家风格

### 三、暴力与血腥限制
- V01 高风险：不得包含明确暴力伤害画面
- V02 高风险：不得描述血液伤口等血腥内容
- V03 中风险：避免武器作为画面主体或特写
- V04 低风险：可通过暗示表达冲突，不能直接展示

### 四、色情与性暗示限制
- S01 高风险：不得包含任何裸露描述
- S02 高风险：不得描述性暗示姿势动作
- S03 中风险：服装不得过度暴露
- S04 低风险：亲密互动需适度

### 五、政治与宗教敏感
- P01 高风险：不得包含政治符号旗帜标语
- P02 高风险：不得生成政治人物形象
- P03 高风险：不得包含亵渎宗教内容
- P04 中风险：宗教场景需中性尊重呈现

### 六、未成年人保护
- M01 高风险：涉及未成年角色不得有不当描述
- M02 中风险：避免未成年角色处于危险暴力场景

### 七、其他平台红线
- O01 高风险：不得展示或美化违禁药物
- O02 高风险：不得包含自残自杀内容
- O03 高风险：不得包含歧视内容
- O04 中风险：过度恐怖画面需避免
- O05 低风险：尽量避免画面中出现文字

## 判定规则

任何高风险项不通过则整体不通过。仅有警告则通过但附修改建议。

## 常见应对策略

武打战斗：用挡闪退格挡代替砍刺劈，聚焦身法气势，远景中景拍摄。

服装暴露：保持合理覆盖度，强调气质姿态，古装参考历史服饰。

恐怖惊悚：用光影构图营造氛围，避免恐怖元素特写，暗示代替直接展示。

## 敏感词自动绕行策略

以下是 Seedance 2.0 平台已知会触发内容过滤的高频敏感词及其安全替代写法。审核时如果发现提示词中包含左列词汇，应自动替换为右列安全用词。

### 动作类敏感词

| 敏感词 | 安全替代 |
|--------|----------|
| 砍、劈、刺、杀 | 挥动、格挡、闪避、交锋 |
| 打、踢、击 | 推开、挡住、接住、化解 |
| 流血、受伤 | 跌倒、后退、踉跄 |
| 爆炸 | 光芒迸发、能量释放、冲击波扩散 |
| 枪、子弹 | 光束、能量弹、信号弹 |
| 死亡、杀死 | 倒下、消散、化为光点 |

### 服装/身体类敏感词

| 敏感词 | 安全替代 |
|--------|----------|
| 裸露、暴露 | 轻薄、飘逸、贴身 |
| 透视 | 薄纱质感、朦胧 |
| 紧身 | 修身剪裁、合身 |
| 胸部/臀部等身体部位特写 | 全身中景、注重气质神态 |

### 氛围/场景类敏感词

| 敏感词 | 安全替代 |
|--------|----------|
| 恐怖、惊悚 | 神秘、悬疑、阴森 |
| 血腥 | 暗红色光影、残阳如血 |
| 尸体 | 倒下的身影、静止的轮廓 |
| 毒品、注射 | 不可替代，直接删除 |

## 版权安全替换策略

当提示词中涉及已有 IP 角色或名人时，不能只是标红删除，要提供视觉上等效的安全替代方案。替换原则：保留色彩方案、服装风格、动作特征、气质氛围，只去掉可识别的身份信息。

### 替换方法

1. 角色名替换为功能性描述："哪吒"替换为"手持火焰长枪的少年战神，红色绸带飘舞，扎双丸子头"
2. 保留视觉关键元素：服装颜色、武器形态、标志性姿态保留，去掉角色名
3. 动作风格保留：招式特点用通用武术语言描述，如"旋风腿""凌空劈砍"
4. 风格参考替换：不说"宫崎骏风格"，说"手绘水彩动画风格，自然光影，温暖色调，精细的植被和云朵细节"

### 替换示例

|----------|----------|
| 哪吒 vs 敖丙 | 火系少年战士（红色主调，双丸子头）vs 水系龙族王子（蓝白色铠甲，长发） |
| 漫威钢铁侠 | 身穿红金色高科技动力装甲的男性英雄，掌心能量发射器发光 |
| 周杰伦弹钢琴 | 一位亚洲男性音乐家，穿黑色西装，低头弹奏三角钢琴，舞台逆光 |
| 迪士尼城堡 | 梦幻童话风格的白色尖塔城堡，蓝紫色暮光，烟花绽放 |
